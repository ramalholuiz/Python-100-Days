## Web Frontend Basics

### HTML Overview

HTML (Hyper-Text Markup Language) is used to describe web pages. HTML elements like text, buttons, images, and videos are rendered by browsers.

### HTML History

- 1991: Tim Berners-Lee published 18 HTML tags
- 1995: HTML 2.0 standard released
- 1997: HTML 3.2 published
- 1997: HTML 4.0 published
- 1999: HTML 4.01 published
- 2008: HTML5 working draft released
- 2014: HTML5 becomes W3C recommendation

### HTML5 New Features

1. Native multimedia support (`audio`, `video` tags)
2. Programmable content (`canvas` tag)
3. Semantic web (article, aside, header, nav, section, footer)
4. New form controls (date, email, range)
5. Better offline storage (localStorage, sessionStorage)
6. Geolocation, drag-and-drop, WebSocket support

### HTML Document Structure

```html
<!DOCTYPE html>
<html>
  <head>
    <title>Page Title</title>
    <meta charset="utf-8">
  </head>
  <body>
    <!-- Page content -->
  </body>
</html>
```

### Key HTML Elements

**Text Elements:**
- Headings: `h1` through `h6`
- Paragraphs: `p`
- Emphasis: `strong`, `em`
- Links: `a href=""`

**Lists:**
- Ordered: `ol` / `li`
- Unordered: `ul` / `li`
- Definition: `dl` / `dt` / `dd`

**Media:**
- Images: `img src="" alt=""`
- Videos: `video controls` `source`
- Audio: `audio controls` `source`

**Forms:**
- Form container: `form`
- Text input: `input type="text"`
- Email: `input type="email"`
- Password: `input type="password"`
- Checkbox: `input type="checkbox"`
- Radio: `input type="radio"`
- Submit: `input type="submit"`
- Textarea: `textarea`
- Select: `select` / `option`

**Semantic Elements:**
- `header`, `nav`, `main`, `article`, `aside`, `footer`, `section`

### CSS Styling

CSS is used to style and layout web pages.

#### Selectors

```css
/* Element selector */
p { color: blue; }

/* Class selector */
.highlight { background-color: yellow; }

/* ID selector */
#main { width: 80%; }

/* Descendant selector */
div p { margin: 10px; }

/* Child selector */
div > p { padding: 5px; }

/* Attribute selector */
input[type="text"] { border: 1px solid gray; }
```

#### Box Model

Every element has: margin → border → padding → content

```css
.box {
    width: 200px;
    padding: 10px;           /* Inside border */
    border: 1px solid black;
    margin: 20px;            /* Outside border */
}
```

#### Common Properties

**Text:**
```css
p {
    font-size: 16px;
    font-family: Arial, sans-serif;
    color: #333;
    line-height: 1.5;
    text-align: center;
}
```

**Background:**
```css
body {
    background-color: white;
    background-image: url('image.jpg');
    background-repeat: no-repeat;
}
```

**Positioning:**
```css
.absolute {
    position: absolute;
    top: 50px;
    left: 100px;
}

.fixed {
    position: fixed;
    bottom: 0;
    right: 0;
}
```

### JavaScript Basics

JavaScript adds interactivity to web pages.

#### Variables and Data Types

```javascript
// Variables
var x = 10;
let name = "Alice";
const PI = 3.14159;

// Data types
typeof 42           // "number"
typeof "hello"      // "string"
typeof true         // "boolean"
typeof {}           // "object"
typeof []           // "object" (array)
typeof undefined    // "undefined"
```

#### Control Structures

```javascript
// if-else
if (age >= 18) {
    console.log("Adult");
} else {
    console.log("Minor");
}

// switch
switch (day) {
    case 1:
        console.log("Monday");
        break;
    default:
        console.log("Other");
}

// for loop
for (let i = 0; i < 5; i++) {
    console.log(i);
}

// while loop
while (condition) {
    // code
}
```

#### Functions

```javascript
// Function declaration
function add(a, b) {
    return a + b;
}

// Arrow function
const multiply = (a, b) => a * b;

// Anonymous function
setTimeout(function() {
    console.log("After 1 second");
}, 1000);
```

#### Arrays and Objects

```javascript
// Arrays
let fruits = ["apple", "banana", "orange"];
fruits.push("grape");
fruits.pop();

// Objects
let person = {
    name: "Alice",
    age: 30,
    email: "alice@example.com"
};

console.log(person.name);      // Access property
person.city = "New York";      // Add property
```

#### DOM Manipulation

```javascript
// Get elements
let element = document.getElementById('myId');
let elements = document.getElementsByClassName('myClass');
let elements = document.querySelectorAll('.item');

// Modify content
element.textContent = "New text";
element.innerHTML = "<h1>Hello</h1>";

// Add/Remove classes
element.classList.add('active');
element.classList.remove('active');

// Event handling
element.addEventListener('click', function() {
    console.log('Clicked!');
});
```

### Summary

- HTML provides structure and content
- CSS handles styling and layout
- JavaScript enables interactivity
- Modern web development uses semantic HTML5 elements
- CSS3 provides advanced styling (flexbox, grid, animations)
- JavaScript frameworks (React, Vue) simplify complex interactions
