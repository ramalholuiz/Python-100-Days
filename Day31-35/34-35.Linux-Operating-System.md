## Linux Operating System

### Operating System Evolution

**Early Computing (Manual Operation):**
- Users loaded programs manually
- CPU idle during human operations
- Very low resource utilization

**Batch Processing Systems:**
- Supervisor program manages job execution
- Automatic job switching
- Improved resource utilization

**Time-sharing Systems:**
- CPU time divided into small time slices
- Multiple users can use system simultaneously
- Each user gets interactive terminal access

**Real-time Systems:**
- Respond to events within strict time constraints
- Critical for industrial and medical applications

**Modern General-Purpose Operating Systems:**
- Multitasking (multiple programs run simultaneously)
- Multi-user (multiple users access system simultaneously)
- Protected memory and file systems
- Modern networking capabilities

### Linux History

1969 - Ken Thompson creates Unics on PDP-7 for Space Travel game

1970-1971 - Ken Thompson and Dennis Ritchie rewrite on PDP-11, rename to Unix

1972-1973 - Dennis Ritchie invents C language, rewrites Unix

1974 - Unix Version 5 released, almost entirely in C

1987 - Andrew Tanenbaum creates Minix for teaching

1991 - Linus Torvalds creates Linux kernel while student at University of Helsinki

### Linux Advantages

1. General-purpose OS, hardware-independent
2. Written in C, highly portable, has kernel API
3. Multi-user and multi-tasking support
4. Secure file system with permission layers
5. Reliable security and stability
6. Developer-friendly with excellent documentation

### Basic Commands

#### User Information

```bash
w               # Who is logged in
who             # User login information
who am i        # Current user
last            # Login history
```

#### Shell and System Info

```bash
ps              # Show current shell/processes
uname           # System information
hostname        # Machine name
date            # Current date and time
cal             # Show calendar
```

#### Help and Documentation

```bash
whatis ps       # Brief description
which ps        # Command location
whereis ps      # All locations
man ps          # Full manual page
ps --help       # Help message
```

#### Basic Operations

```bash
clear           # Clear screen
exit            # Exit shell
logout          # Logout
history         # Show command history
!454            # Repeat command 454
```

### File and Directory Operations

#### Directory Operations

```bash
mkdir abc           # Create directory
mkdir -p a/b/c      # Create nested directories
rmdir abc           # Remove empty directory
pwd                 # Current directory
cd /path            # Change directory
cd ..               # Go up one level
```

#### File Operations

```bash
touch file.txt              # Create empty file
rm file.txt                 # Delete file
rm -r directory/            # Delete directory recursively
rm -f file.txt              # Force delete
```

#### List Directory

```bash
ls                  # List files
ls -l               # Long format
ls -a               # Show hidden files
ls -R               # Recursive
ls -S               # Sort by size
ls -t               # Sort by time
```

#### View File Contents

```bash
cat file.txt        # Display entire file
head -10 file.txt   # First 10 lines
tail -10 file.txt   # Last 10 lines
more file.txt       # Paginated view
less file.txt       # Paginated with navigation
```

#### File Operations

```bash
cp source dest              # Copy file
cp -r directory/ dest/      # Copy directory
mv source dest              # Move/rename
wc file.txt                 # Count lines, words, characters
diff file1 file.txt2        # Show differences
```

### Text Processing

#### grep - Search Text

```bash
grep "pattern" file.txt     # Find pattern
grep -i "pattern" file.txt  # Case-insensitive
grep -n "pattern" file.txt  # Show line numbers
grep -v "pattern" file.txt  # Inverse match
```

#### sed - Stream Editor

```bash
sed 's/old/new/' file.txt           # Replace first occurrence per line
sed 's/old/new/g' file.txt          # Replace all occurrences
sed '2d' file.txt                   # Delete line 2
sed -n '1,5p' file.txt              # Print lines 1-5
```

#### awk - Text Processing

```bash
awk '{print $1}' file.txt           # Print first field
awk -F: '{print $1}' /etc/passwd    # Use colon delimiter
awk '{sum += $1} END {print sum}' file.txt  # Sum first column
```

### File Permissions

```bash
ls -l
# -rw-r--r-- 1 user group 1024 Jun 20 12:34 file.txt
# Permissions: owner, group, others (read/write/execute)

chmod 755 script.sh         # rwxr-xr-x
chmod u+x script.sh         # Add execute for owner
chmod 644 file.txt          # rw-r--r--
```

### Process Management

ps                  # Show processes

### Network Commands

### Disk and Storage
