## Python Learning Resources Summary

Many people search for Python learning resources online, but the quality varies greatly. Some highly-rated content doesn't actually help people with real learning needs. Here, I've compiled the best learning resources to help you avoid detours.

> **Tip**: Just pick the resources that suit you - not every one is worth your time to study.

These courses are concise and get straight to the point, unlike some training institutions that share 700-episode courses or 800GB of materials, making people think bookmarking equals learning. There are many learning platforms both domestic and international - some prefer Udemy, others Coursera. I'm just sharing courses I've personally watched and found valuable. What matters most is having a learning plan and actually following through.

### Python Reference Books

#### Beginner Books

1. *Python Crash Course* - The famous "snake book", recommended
2. *Beginning Python From Novice to Professional* - Classic introduction
3. *Learning Python* - The famous "rat book"
4. *Introduction to Computation and Programming Using Python* - A personal favorite

#### Intermediate Books

1. *Python Cookbook* - Follow the recipes, can't go wrong. Top pick for intermediate learners
2. *Fluent Python* - Essential reading on the path to mastery
3. *Effective Python: 59 Specific Ways to Write Better Python*
4. *Expert Python Programming* - The famous "flower book"
5. *Python Project Development in Practice* - Lots of engineering knowledge

#### Web Scraping

1. *Web Scraping with Python 3 in Practice* - Personally recommended
2. *Web Scraping with Python* - The famous "pangolin book"

#### Data Analysis

1. *Python for Data Analysis* - Written by the creator of pandas
2. *Python Data Science Handbook* - O'Reilly's iguana book
3. *Python Data Analytics With Pandas, NumPy, and Matplotlib* - Personally recommended
4. *Python Data Visualization Cookbook* - Focus on data visualization
5. *Principles of Data Science* - A personal favorite
6. *Practical Statistics for Data Scientists* - Very practical statistics
7. *Data Science from Scratch*

#### Machine Learning

1. *Machine Learning in Action* - Recommended for beginners
2. *Machine Learning (Iris Flower Mathematical Series)* - Dr. Jiang Weisheng's carefully crafted work
3. *Deep Learning from Scratch: Theory and Implementation with Python* - Award-winning Japanese book, recommended for beginners
4. *Deep Learning* - The classic deep learning masterpiece
5. *Dive into Deep Learning* - By Aston Zhang and Mu Li
6. *Deep Learning with Python* - A personal favorite
7. *Hands-On Machine Learning with Scikit-Learn, Keras, and TensorFlow* - The famous "lizard book", from ML to DL

#### Large Language Models

1. *Getting Started with Google BERT* - Five-star rated book
2. *Build a Large Language Model*
3. *Hands-On Large Language Models*
4. *Developing Apps with GPT-4 and ChatGPT*

#### Testing and DevOps

1. *Learning Selenium Testing Tools with Python*
2. *Python Testing with pytest*
3. *Hands-On Enterprise Automation with Python*
4. *Python DevOps: Technology and Best Practices*
