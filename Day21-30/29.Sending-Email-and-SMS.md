## Sending Email and SMS

Python can automate sending emails and SMS messages through server integration.

### Sending Email

#### Simple Email

```python
import smtplib
from email.mime.text import MIMEText
from email.header import Header

# Create email
email = MIMEText('Hello! This is the email content.', 'plain', 'utf-8')
email['From'] = 'sender@126.com'
email['To'] = 'recipient@qq.com'
email['Subject'] = Header('Email Subject', 'utf-8')

# Connect to SMTP server and send
smtp = smtplib.SMTP_SSL('smtp.126.com', 465)
smtp.login('sender@126.com', 'authorization_code')
smtp.sendmail('sender@126.com', ['recipient@qq.com'], email.as_string())
smtp.quit()
```

#### Email with Attachments

```python
import smtplib
from email.mime.multipart import MIMEMultipart
from email.mime.text import MIMEText
from email.mime.base import MIMEBase
from email import encoders
from email.header import Header

# Create multipart email
email = MIMEMultipart()
email['From'] = 'sender@126.com'
email['To'] = 'recipient@qq.com'
email['Subject'] = Header('Email with Attachment', 'utf-8')

# Add body
body = MIMEText('Please find the attachment.', 'plain', 'utf-8')
email.attach(body)

# Add attachment
with open('document.pdf', 'rb') as attachment:
    part = MIMEBase('application', 'octet-stream')
    part.set_payload(attachment.read())
    encoders.encode_base64(part)
    part.add_header('Content-Disposition', 'attachment', filename='document.pdf')
    email.attach(part)

# Send email
smtp = smtplib.SMTP_SSL('smtp.126.com', 465)
smtp.login('sender@126.com', 'authorization_code')
smtp.sendmail('sender@126.com', ['recipient@qq.com'], email.as_string())
smtp.quit()
```

#### Email to Multiple Recipients

```python
import smtplib
from email.mime.text import MIMEText
from email.header import Header

email = MIMEText('Message content', 'plain', 'utf-8')
email['From'] = 'sender@126.com'
email['To'] = 'recipient1@qq.com;recipient2@qq.com'
email['Subject'] = Header('Subject', 'utf-8')

recipients = ['recipient1@qq.com', 'recipient2@qq.com', 'recipient3@qq.com']

smtp = smtplib.SMTP_SSL('smtp.126.com', 465)
smtp.login('sender@126.com', 'authorization_code')
smtp.sendmail('sender@126.com', recipients, email.as_string())
smtp.quit()
```

### SMS Services

For SMS, use third-party services:

#### Using Twilio (Popular Service)

```bash
pip install twilio
```

```python
from twilio.rest import Client

# Twilio credentials
account_sid = 'your_account_sid'
auth_token = 'your_auth_token'
client = Client(account_sid, auth_token)

# Send SMS
message = client.messages.create(
    body='Hello! This is a test SMS.',
    from_='+1234567890',  # Your Twilio phone number
    to='+9876543210'      # Recipient phone number
)

print(f"SMS sent with SID: {message.sid}")
```

#### Using Alibaba Cloud SMS (China)

```python
# Install Alibaba SDK
# pip install aliyun-python-sdk-core

from aliyunsdkcore.client import AcsClient
from aliyunsdkcore.request import CommonRequest

# Configure client
client = AcsClient('access_key', 'secret_key', 'cn-beijing')

# Create request
request = CommonRequest()
request.set_protocol_type('https')
request.set_method('POST')
request.set_domain('dysmsapi.aliyuncs.com')
request.set_action_name('SendSms')
request.add_query_param('RegionId', 'cn-beijing')
request.add_query_param('PhoneNumbers', '13900000000')
request.add_query_param('SignName', 'YourSignName')
request.add_query_param('TemplateCode', 'SMS_000000')
request.add_query_param('TemplateParam', '{"code":"123456"}')

# Send SMS
response = client.do_action_with_exception(request)
print(response.decode('utf-8'))
```

### Best Practices

```python
import smtplib
from email.mime.text import MIMEText
from email.header import Header

def send_email(sender, password, recipient, subject, content):
    """Send email with error handling"""
    try:
        email = MIMEText(content, 'plain', 'utf-8')
        email['From'] = sender
        email['To'] = recipient
        email['Subject'] = Header(subject, 'utf-8')
        
        smtp = smtplib.SMTP_SSL('smtp.126.com', 465)
        smtp.login(sender, password)
        smtp.sendmail(sender, [recipient], email.as_string())
        smtp.quit()
        
        print("Email sent successfully!")
        return True
    except Exception as e:
        print(f"Error sending email: {e}")
        return False

# Usage
send_email('sender@126.com', 'auth_code', 'recipient@qq.com', 
           'Subject', 'Message content')
```

### Summary

- Use `smtplib` for sending emails
- Use `email.mime` modules for message construction
- Support plain text, HTML, and attachments
- Use authorization codes instead of passwords for security
- Third-party services (Twilio, Alibaba) for SMS
- Implement error handling for production code
