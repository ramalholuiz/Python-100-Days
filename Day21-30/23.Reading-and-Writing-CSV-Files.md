## Reading and Writing CSV Files

### CSV Format Introduction

CSV (Comma-Separated Values) is a simple, universal file format used for data import/export and data exchange between heterogeneous systems.

CSV file characteristics:
1. Pure text using character sets (ASCII, Unicode, etc.)
2. Composed of records (typically one per line)
3. Each record is separated by delimiters (comma, semicolon, tab)
4. All records have the same field sequence

### Writing to CSV Files

```python
import csv
import random

with open('scores.csv', 'w', newline='', encoding='utf-8') as file:
    writer = csv.writer(file)
    writer.writerow(['Name', 'Chinese', 'Math', 'English'])
    
    names = ['Alice', 'Bob', 'Charlie', 'David', 'Eve']
    for name in names:
        scores = [random.randrange(50, 101) for _ in range(3)]
        scores.insert(0, name)
        writer.writerow(scores)
```

Generated CSV content:
```
Name,Chinese,Math,English
Alice,98,86,61
Bob,86,58,80
Charlie,95,73,70
David,83,97,55
Eve,61,54,87
```

### Custom Delimiters

```python
import csv

with open('scores.csv', 'w', newline='', encoding='utf-8') as file:
    writer = csv.writer(file, delimiter='|', quoting=csv.QUOTE_ALL)
    writer.writerow(['Name', 'Chinese', 'Math', 'English'])
    writer.writerow(['Alice', 98, 86, 61])
```

### Reading from CSV Files

```python
import csv

with open('scores.csv', 'r', encoding='utf-8') as file:
    reader = csv.reader(file)
    for row in reader:
        print(reader.line_num, end='\t')
        for value in row:
            print(value, end='\t')
        print()
```

### DictReader and DictWriter

```python
import csv

# Write using DictWriter
with open('scores.csv', 'w', newline='', encoding='utf-8') as file:
    fieldnames = ['Name', 'Chinese', 'Math', 'English']
    writer = csv.DictWriter(file, fieldnames=fieldnames)
    writer.writeheader()
    writer.writerow({'Name': 'Alice', 'Chinese': 98, 'Math': 86, 'English': 61})

# Read using DictReader
with open('scores.csv', 'r', encoding='utf-8') as file:
    reader = csv.DictReader(file)
    for row in reader:
        print(row)  # Returns OrderedDict
```

### Using Pandas

For complex CSV operations, use pandas:

```python
import pandas as pd

# Read CSV
df = pd.read_csv('scores.csv')
print(df)

# Write CSV
df.to_csv('output.csv', index=False, encoding='utf-8')
```

### Summary

- CSV is widely used for data exchange
- Use `csv.writer()` and `csv.reader()` for basic operations
- Use `csv.DictWriter()` and `csv.DictReader()` for dictionary-based operations
- Pandas provides powerful CSV processing capabilities
- Always use `newline=''` parameter when opening CSV files
