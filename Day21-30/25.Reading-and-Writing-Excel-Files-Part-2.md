## Reading and Writing Excel Files - Part 2

### OpenPyXL Introduction

`openpyxl` is a modern library for reading/writing Excel 2007+ files (.xlsx). It's more convenient than `xlrd`/`xlwt` and supports both reading and writing on the same file.

Install the library:
```bash
pip install openpyxl
```

### Reading Excel Files with OpenPyXL

```python
import datetime
import openpyxl

# Load workbook
wb = openpyxl.load_workbook('alibaba_2020.xlsx')

# Get sheet names
print(wb.sheetnames)

# Get worksheet
sheet = wb.worksheets[0]

# Get dimensions
print(sheet.dimensions)
print(sheet.max_row, sheet.max_column)

# Read specific cells
print(sheet.cell(3, 3).value)
print(sheet['C3'].value)

# Read range of cells
cells = sheet['A2:C5']

# Read all data
for row_ch in range(2, sheet.max_row + 1):
    for col_ch in 'ABCDEFG':
        value = sheet[f'{col_ch}{row_ch}'].value
        
        # Format by type
        if isinstance(value, datetime.datetime):
            print(value.strftime('%Y-%m-%d'), end='\t')
        elif isinstance(value, (int, float)):
            print(f'{value:.4f}', end='\t')
        else:
            print(value, end='\t')
    print()
```

### Writing Excel Files with OpenPyXL

```python
import random
import openpyxl

# Create workbook
wb = openpyxl.Workbook()

# Get active worksheet
sheet = wb.active
sheet.title = 'Final Grades'

# Add header
titles = ('Name', 'Chinese', 'Math', 'English')
for col_index, title in enumerate(titles, 1):
    sheet.cell(1, col_index, title)

# Add data
names = ('Alice', 'Bob', 'Charlie', 'David', 'Eve')
for row_index, name in enumerate(names, 2):
    sheet.cell(row_index, 1, name)
    for col_index in range(2, 5):
        sheet.cell(row_index, col_index, random.randrange(50, 101))

# Save
wb.save('grades.xlsx')
```

### Styling Cells

```python
import openpyxl
from openpyxl.styles import Font, Alignment, PatternFill, Border, Side

# Font styling
cell = sheet['A1']
cell.font = Font(name='Arial', size=12, bold=True, color='FF0000')

# Alignment
cell.alignment = Alignment(horizontal='center', vertical='center', wrap_text=True)

# Fill color
cell.fill = PatternFill(start_color='FFFF00', end_color='FFFF00', fill_type='solid')

# Border
thin_border = Border(
    left=Side(style='thin'),
    right=Side(style='thin'),
    top=Side(style='thin'),
    bottom=Side(style='thin')
)
cell.border = thin_border
```

### Formulas and Calculations

```python
import openpyxl

# Open workbook
wb = openpyxl.load_workbook('grades.xlsx')
sheet = wb.active

# Add formulas
sheet['E2'] = '=B2+C2+D2'  # Sum
sheet['F2'] = '=AVERAGE(B2:D2)'  # Average

# Apply formula to multiple rows
for row in range(2, sheet.max_row + 1):
    sheet[f'E{row}'] = f'=B{row}+C{row}+D{row}'
    sheet[f'F{row}'] = f'=AVERAGE(B{row}:D{row})'

wb.save('grades.xlsx')
```

### Inserting Rows and Columns

```python
import openpyxl

wb = openpyxl.load_workbook('grades.xlsx')
sheet = wb.active

# Insert row at index 2
sheet.insert_rows(2, 5)  # Insert 5 rows starting at row 2

# Insert column at index 2
sheet.insert_cols(2, 3)  # Insert 3 columns starting at column 2

wb.save('grades.xlsx')
```

### Summary

- `openpyxl` provides modern Excel file handling
- Access cells using both notation: `cell()` method or `['A1']` syntax
- Apply comprehensive styling (fonts, colors, borders, alignment)
- Use formulas for calculations
- Manipulate rows and columns easily
- More powerful than `xlrd`/`xlwt` for modern Excel files
