## Working with PDF Files

PDF (Portable Document Format) is widely used for document sharing. Python can read from and write to PDF files.

### Reading PDF Files

Install `PyPDF2`:
```bash
pip install PyPDF2
```

### Extracting Text from PDF

```python
import PyPDF2

# Open PDF file
with open('document.pdf', 'rb') as file:
    reader = PyPDF2.PdfReader(file)
    
    # Iterate through pages
    for page_num in range(len(reader.pages)):
        page = reader.pages[page_num]
        text = page.extract_text()
        print(f"Page {page_num + 1}:")
        print(text)
```

### Getting PDF Information

```python
import PyPDF2

with open('document.pdf', 'rb') as file:
    reader = PyPDF2.PdfReader(file)
    
    # Number of pages
    num_pages = len(reader.pages)
    print(f"Total pages: {num_pages}")
    
    # Document metadata
    if reader.metadata:
        print(f"Title: {reader.metadata.title}")
        print(f"Author: {reader.metadata.author}")
```

### Rotating Pages

```python
import PyPDF2

reader = PyPDF2.PdfReader('document.pdf')
writer = PyPDF2.PdfWriter()

for page in reader.pages:
    # Rotate page 90 degrees clockwise
    rotated_page = page.rotate(90)
    writer.add_page(rotated_page)

with open('rotated.pdf', 'wb') as file:
    writer.write(file)
```

### Merging PDF Files

```python
import PyPDF2

writer = PyPDF2.PdfWriter()

# Read and merge multiple PDF files
pdf_files = ['document1.pdf', 'document2.pdf', 'document3.pdf']

for pdf_file in pdf_files:
    with open(pdf_file, 'rb') as file:
        reader = PyPDF2.PdfReader(file)
        for page in reader.pages:
            writer.add_page(page)

with open('merged.pdf', 'wb') as file:
    writer.write(file)
```

### Encrypting PDF Files

```python
import PyPDF2

reader = PyPDF2.PdfReader('document.pdf')
writer = PyPDF2.PdfWriter()

# Add all pages
for page in reader.pages:
    writer.add_page(page)

# Encrypt with password
writer.encrypt('password123')

with open('encrypted.pdf', 'wb') as file:
    writer.write(file)
```

### Adding Watermarks

```python
import PyPDF2

# Create watermark (a PDF with watermark text)
reader = PyPDF2.PdfReader('document.pdf')
watermark_reader = PyPDF2.PdfReader('watermark.pdf')
writer = PyPDF2.PdfWriter()

watermark_page = watermark_reader.pages[0]

# Apply watermark to each page
for page in reader.pages:
    page.merge_page(watermark_page)
    writer.add_page(page)

with open('watermarked.pdf', 'wb') as file:
    writer.write(file)
```

### Extracting Pages

```python
import PyPDF2

reader = PyPDF2.PdfReader('document.pdf')
writer = PyPDF2.PdfWriter()

# Extract specific pages (e.g., pages 1-5)
for page_num in range(0, min(5, len(reader.pages))):
    writer.add_page(reader.pages[page_num])

with open('extracted.pdf', 'wb') as file:
    writer.write(file)
```

### Summary

- Use `PyPDF2` for reading and manipulating PDF files
- Extract text from PDF pages
- Rotate, merge, and split PDF files
- Encrypt PDFs with passwords
- Add watermarks to documents
- Extract specific page ranges
- Note: Text extraction works better with text-based PDFs, not scanned images
