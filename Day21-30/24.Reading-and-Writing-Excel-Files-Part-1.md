## Reading and Writing Excel Files - Part 1

### Excel Introduction

Excel is a spreadsheet software developed by Microsoft. It's the most popular personal computer data processing software due to its intuitive interface, powerful calculation functions, and charting tools.

For Python to work with Excel files in .xls format (Excel 2007 and earlier), use `xlrd` (reading) and `xlwt` (writing). For newer .xlsx format, use `openpyxl`.

Install the required libraries:
```bash
pip install xlwt xlrd xlutils
```

### Reading Excel Files

```python
import xlrd

# Open workbook
wb = xlrd.open_workbook('alibaba_2020.xls')

# Get sheet names
sheetnames = wb.sheet_names()
print(sheetnames)

# Get sheet
sheet = wb.sheet_by_name(sheetnames[0])

# Get dimensions
print(sheet.nrows, sheet.ncols)

# Read cells
for row in range(sheet.nrows):
    for col in range(sheet.ncols):
        value = sheet.cell(row, col).value
        
        # Format date columns
        if row > 0 and col == 0:
            value = xlrd.xldate_as_tuple(value, 0)
            value = f'{value[0]}-{value[1]:>02d}-{value[2]:>02d}'
        # Format numeric columns
        elif row > 0:
            value = f'{value:.2f}'
        print(value, end='\t')
    print()
```

### Writing Excel Files

```python
import random
import xlwt

# Create workbook
wb = xlwt.Workbook()

# Add worksheet
sheet = wb.add_sheet('Grade 1 Class 2')

# Add header
titles = ('Name', 'Chinese', 'Math', 'English')
for index, title in enumerate(titles):
    sheet.write(0, index, title)

# Add data
student_names = ['Alice', 'Bob', 'Charlie', 'David', 'Eve']
scores = [[random.randrange(50, 101) for _ in range(3)] for _ in range(5)]

for row in range(len(scores)):
    sheet.write(row + 1, 0, student_names[row])
    for col in range(len(scores[row])):
        sheet.write(row + 1, col + 1, scores[row][col])

# Save
wb.save('grades.xls')
```

### Cell Styling

```python
import xlwt

# Create style
header_style = xlwt.XFStyle()

# Set font
font = xlwt.Font()
font.name = 'Arial'
font.height = 200  # Height in twips (1/20 pt)
font.bold = True
header_style.font = font

# Set background color
pattern = xlwt.Pattern()
pattern.pattern = xlwt.Pattern.SOLID_PATTERN
pattern.pattern_fore_colour = 5  # Yellow
header_style.pattern = pattern

# Set alignment
alignment = xlwt.Alignment()
alignment.horz = xlwt.Alignment.HORZ_CENTER
alignment.vert = xlwt.Alignment.VERT_CENTER
header_style.alignment = alignment

# Apply style
sheet.write(0, 0, 'Name', header_style)
```

### Summary

- `xlrd` reads Excel files
- `xlwt` writes Excel files
- Access sheets by name or index
- Format dates and numbers appropriately
- Apply styles for better presentation
