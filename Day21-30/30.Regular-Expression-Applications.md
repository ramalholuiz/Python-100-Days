## Regular Expression Applications

Regular expressions are tools for pattern matching in text. They define rules for finding, extracting, or replacing text patterns.

### Basic Concepts

Regular expressions use special characters to define patterns:

| Symbol | Meaning |
|--------|---------|
| `.` | Any character |
| `\w` | Word character (letter, digit, underscore) |
| `\d` | Digit |
| `\s` | Whitespace |
| `^` | Start of string |
| `$` | End of string |
| `*` | 0 or more times |
| `+` | 1 or more times |
| `?` | 0 or 1 time |
| `{n}` | Exactly n times |
| `{n,m}` | Between n and m times |
| `[]` | Character set |
| `[^]` | Not in character set |
| `|` | OR |
| `()` | Group |

### Using the `re` Module

```python
import re

# Common functions
re.match(pattern, string)      # Match at start
re.search(pattern, string)     # Find first match
re.findall(pattern, string)    # Find all matches
re.sub(pattern, repl, string)  # Replace pattern
re.split(pattern, string)      # Split by pattern
```

### Example 1: Validating Username and QQ Number

```python
import re

def validate_credentials(username, qq):
    """
    Username: 6-20 characters, letters/digits/underscore only
    QQ: 5-12 digits, first digit not 0
    """
    
    # Validate username
    if re.fullmatch(r'\w{6,20}', username):
        print(f"✓ Username '{username}' is valid")
    else:
        print(f"✗ Username '{username}' is invalid")
    
    # Validate QQ
    if re.fullmatch(r'[1-9]\d{4,11}', qq):
        print(f"✓ QQ '{qq}' is valid")
    else:
        print(f"✗ QQ '{qq}' is invalid")

# Test
validate_credentials('user_123', '12345')      # Valid
validate_credentials('ab', '000123')           # Invalid
validate_credentials('user@name', '12345')     # Invalid username
```

### Example 2: Extracting Email Addresses

```python
import re

text = """
Contact us at: support@example.com or sales@company.org
For inquiries: admin@test.co.uk
"""

# Extract emails
emails = re.findall(r'\b[A-Za-z0-9._%+-]+@[A-Za-z0-9.-]+\.[A-Z|a-z]{2,}\b', text)
print(emails)
# Output: ['support@example.com', 'sales@company.org', 'admin@test.co.uk']
```

### Example 3: Phone Number Validation

```python
import re

def validate_phone(phone):
    """Validate Chinese mobile phone number"""
    if re.fullmatch(r'1[3-9]\d{9}', phone):
        print(f"✓ Phone '{phone}' is valid")
    else:
        print(f"✗ Phone '{phone}' is invalid")

validate_phone('13800000000')  # Valid
validate_phone('12800000000')  # Invalid
```

### Example 4: Finding URLs

```python
import re

text = "Visit https://www.python.org or http://docs.python.org for documentation"

# Extract URLs
urls = re.findall(r'https?://[^\s]+', text)
print(urls)
# Output: ['https://www.python.org', 'http://docs.python.org']
```

### Example 5: Replacing Patterns

```python
import re

text = "The date is 2024-02-23, and the year is 2024."

# Replace year with something else
result = re.sub(r'\b202\d\b', 'YYYY', text)
print(result)
# Output: "The date is YYYY-02-23, and the year is YYYY."

# Replace email addresses
text = "Email: john@example.com or jane@example.com"
result = re.sub(r'\b[A-Za-z0-9._%+-]+@[A-Za-z0-9.-]+\.[A-Z|a-z]{2,}\b', '[EMAIL]', text)
print(result)
# Output: "Email: [EMAIL] or [EMAIL]"
```

### Example 6: Splitting Text

```python
import re

# Split by whitespace or comma
text = "apple, banana  orange pear,  grape"
words = re.split(r'[,\s]+', text)
print(words)
# Output: ['apple', 'banana', 'orange', 'pear', 'grape']
```

### Example 7: Extracting Numbers

```python
import re

text = "The prices are: $10.50, $25.99, and $5.00"

# Extract numbers
prices = re.findall(r'\$(\d+\.\d{2})', text)
print(prices)
# Output: ['10.50', '25.99', '5.00']
```

### Example 8: Case-Insensitive Matching

```python
import re

text = "Hello HELLO hello HeLLo"

# Case-insensitive search
matches = re.findall(r'hello', text, re.IGNORECASE)
print(matches)
# Output: ['Hello', 'HELLO', 'hello', 'HeLLo']
```

### Compiling Regular Expressions

For repeated use, compile the pattern:

```python
import re

# Compile pattern
pattern = re.compile(r'\d{3}-\d{3}-\d{4}')

text = "Call 555-123-4567 or 555-987-6543"

# Use compiled pattern
matches = pattern.findall(text)
print(matches)
```

### Summary

- Regular expressions are powerful for text pattern matching
- Use `re.match()` for start, `re.search()` for anywhere
- Use `findall()` to get all matches as a list
- Use `sub()` to replace patterns
- Use `re.IGNORECASE` flag for case-insensitive matching
- Compile patterns for repeated use
- Test regex patterns carefully for edge cases
- Learn regex gradually starting with simple patterns
