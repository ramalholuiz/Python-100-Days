## Working with Word and PowerPoint Files

Python can automate batch generation of Word and PowerPoint files. Word is a word processing program, and PowerPoint is a presentation program.

### Working with Word Documents

Install `python-docx`:
```bash
pip install python-docx
```

### Creating a Word Document

```python
from docx import Document
from docx.shared import Cm, Pt, RGBColor

# Create document
document = Document()

# Add title
document.add_heading('Learning Python', 0)

# Add paragraph
p = document.add_paragraph('Python is a ')
run = p.add_run('simple')
run.bold = True
run.font.size = Pt(18)
p.add_run(' and ')
run = p.add_run('elegant')
run.font.size = Pt(18)
run.underline = True
p.add_run(' language.')

# Add heading
document.add_heading('Features', level=1)

# Add bulleted list
document.add_paragraph('Easy to learn', style='List Bullet')
document.add_paragraph('Powerful', style='List Bullet')

# Add numbered list
document.add_paragraph('Object-oriented', style='List Number')
document.add_paragraph('Functional', style='List Number')

# Add image
document.add_picture('python_logo.png', width=Cm(5.2))

# Add table
table = document.add_table(rows=1, cols=3)
table.style = 'Dark List'
hdr_cells = table.rows[0].cells
hdr_cells[0].text = 'Name'
hdr_cells[1].text = 'Gender'
hdr_cells[2].text = 'Birth Date'

# Add rows to table
records = [
    ('Alice', 'Female', '1995-05-05'),
    ('Bob', 'Male', '1992-02-02')
]
for name, gender, birth_date in records:
    row_cells = table.add_row().cells
    row_cells[0].text = name
    row_cells[1].text = gender
    row_cells[2].text = birth_date

# Add page break
document.add_page_break()

# Save document
document.save('document.docx')
```

### Reading a Word Document

```python
from docx import Document

# Open document
doc = Document('document.docx')

# Read paragraphs
for no, p in enumerate(doc.paragraphs):
    print(f"{no}: {p.text}")

# Read table
for table in doc.tables:
    for row in table.rows:
        for cell in row.cells:
            print(cell.text, end='\t')
        print()
```

### Working with PowerPoint

Install `python-pptx`:
```bash
pip install python-pptx
```

### Creating a PowerPoint Presentation

```python
from pptx import Presentation
from pptx.util import Inches, Pt

# Create presentation
prs = Presentation()

# Set slide dimensions
prs.slide_width = Inches(10)
prs.slide_height = Inches(7.5)

# Add title slide
title_slide_layout = prs.slide_layouts[0]
slide = prs.slides.add_slide(title_slide_layout)
title = slide.shapes.title
subtitle = slide.placeholders[1]
title.text = "Python Programming"
subtitle.text = "A Beginner's Guide"

# Add content slide
bullet_slide_layout = prs.slide_layouts[1]
slide = prs.slides.add_slide(bullet_slide_layout)
shapes = slide.shapes

title_shape = shapes.title
body_shape = shapes.placeholders[1]

title_shape.text = "Why Python?"
text_frame = body_shape.text_frame
text_frame.text = "Simple and readable"

# Add bullet points
p = text_frame.add_paragraph()
p.text = "Powerful libraries"
p.level = 0

p = text_frame.add_paragraph()
p.text = "Active community"
p.level = 0

# Save presentation
prs.save('presentation.pptx')
```

### Adding Images and Shapes to Slides

```python
from pptx import Presentation
from pptx.util import Inches, Pt
from pptx.enum.shapes import MSO_SHAPE

prs = Presentation()
slide = prs.slides.add_slide(prs.slide_layouts[6])

# Add image
left = Inches(1)
top = Inches(1)
height = Inches(2)
pic = slide.shapes.add_picture('python_logo.png', left, top, height=height)

# Add shape
left = Inches(4)
top = Inches(1)
width = Inches(3)
height = Inches(2)
shape = slide.shapes.add_shape(MSO_SHAPE.ROUNDED_RECTANGLE, left, top, width, height)
shape.text = "Hello!"

prs.save('presentation.pptx')
```

### Summary

- `python-docx` for Word document creation and editing
- `python-pptx` for PowerPoint presentation creation
- Add text, images, tables, shapes to documents and slides
- Format text with fonts, colors, sizes
- Automate bulk document generation for batch operations
