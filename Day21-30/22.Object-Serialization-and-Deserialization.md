## Object Serialization and Deserialization

### JSON Overview

From the previous lessons, we already know how to save text and binary data to files. But there's another question: what if we want to save data from a list or dictionary to a file? In Python, we can save program data in JSON format. JSON stands for "JavaScript Object Notation" — it was originally a literal syntax for creating objects in JavaScript, but it is now widely used for cross-language, cross-platform data exchange. The reason for using JSON is very simple: it has a compact structure and is plain text. Any operating system and programming language can process plain text, which is the prerequisite for **cross-language, cross-platform data exchange**. JSON has essentially replaced XML (Extensible Markup Language) as the **de facto standard for data exchange between heterogeneous systems**. You can find more information about JSON on [the official JSON website](https://www.json.org/json-zh.html), which also provides tools and third-party libraries for processing JSON data in various languages.

```JavaScript
{
    name: "骆昊",
    age: 40,
    friends: ["王大锤", "白元芳"],
    cars: [
        {"brand": "BMW", "max_speed": 240},
        {"brand": "Benz", "max_speed": 280},
        {"brand": "Audi", "max_speed": 280}
    ]
}
```

The above is a simple JSON example. As you may have noticed, it is very similar to a Python dictionary and supports nested structures, just like how a Python dictionary's value can be another dictionary. We can try entering the following code into the browser's console (for Chrome, you can find "Developer Tools" under the "More Tools" menu to open the browser console). The browser console provides an interactive environment for running JavaScript code (similar to Python's interactive environment). The code below will create a JavaScript object and assign it to a variable named `obj`.

```JavaScript
let obj = {
    name: "骆昊",
    age: 40,
    friends: ["王大锤", "白元芳"],
    cars: [
        {"brand": "BMW", "max_speed": 240},
        {"brand": "Benz", "max_speed": 280},
        {"brand": "Audi", "max_speed": 280}
    ]
}
```

### Reading and Writing JSON Data

In Python, to convert a dictionary to JSON format (as a string), you can use the `dumps` function from the `json` module, as shown below.

```python
import json

my_dict = {
    'name': '骆昊',
    'age': 40,
    'friends': ['王大锤', '白元芳'],
    'cars': [
        {'brand': 'BMW', 'max_speed': 240},
        {'brand': 'Audi', 'max_speed': 280},
        {'brand': 'Benz', 'max_speed': 280}
    ]
}
print(json.dumps(my_dict))
```

Running the code above produces the following output. Notice that Chinese characters are displayed using Unicode encoding.

```JSON
{"name": "\u9a86\u660a", "age": 40, "friends": ["\u738b\u5927\u9524", "\u767d\u5143\u82b3"], "cars": [{"brand": "BMW", "max_speed": 240}, {"brand": "Audi", "max_speed": 280}, {"brand": "Benz", "max_speed": 280}]}
```

To convert a dictionary to JSON format and write it to a text file, simply replace the `dumps` function with `dump` and pass in a file object, as shown below.

```python
import json

my_dict = {
    'name': '骆昊',
    'age': 40,
    'friends': ['王大锤', '白元芳'],
    'cars': [
        {'brand': 'BMW', 'max_speed': 240},
        {'brand': 'Audi', 'max_speed': 280},
        {'brand': 'Benz', 'max_speed': 280}
    ]
}
with open('data.json', 'w') as file:
    json.dump(my_dict, file)
```

Executing the code above will create a `data.json` file with the same content as the output of the previous code.

The `json` module has four important functions:

- `dump` - Serializes a Python object to a file in JSON format
- `dumps` - Converts a Python object to a JSON-formatted string
- `load` - Deserializes JSON data from a file into an object
- `loads` - Deserializes string content into a Python object

Two concepts appear here: serialization and deserialization. According to [Wikipedia](https://zh.wikipedia.org/): "Serialization in computer science data processing refers to converting a data structure or object state into a form that can be stored or transmitted, so that the original state can be restored when needed. Through the serialized data, bytes can be used to create a copy of the original object. The reverse process, extracting a data structure from a series of bytes, is deserialization."

We can read the `data.json` file created above and restore the JSON-formatted data back to a Python dictionary using the following code.

```python
import json

with open('data.json', 'r') as file:
    my_dict = json.load(file)
    print(type(my_dict))
    print(my_dict)
```

### Package Management Tool pip

The `json` module in Python's standard library doesn't have ideal performance for serialization and deserialization. To solve this problem, you can use the third-party library `ujson` as a replacement for `json`. Third-party libraries refer to Python modules that are not developed and used internally by a company, nor are they from the official standard library. These modules are typically developed by other companies, organizations, or individuals, hence the name "third-party libraries." Although Python's standard library already provides many modules to facilitate development, for a powerful language, its ecosystem must also be very prosperous.

When installing the Python interpreter, pip is installed by default. You can verify whether you already have pip by running `pip --version` in the command prompt or terminal. Pip is Python's package management tool — through pip, you can find, install, uninstall, and update Python third-party libraries or tools. For example, to install `ujson` as a replacement for the `json` module, you can use the following command.

```Bash
pip install ujson
```

By default, pip accesses `https://pypi.org/simple/` to get third-party library data. However, accessing this site from within China may not be very fast, so Chinese users can use mirrors provided by Douban or Tsinghua University to replace the default download source before installing third-party libraries, as shown below.

```Bash
pip config set global.index-url https://pypi.doubanio.com/simple
pip install ujson
```

You can use the `pip search` command to find third-party libraries by name, and the `pip list` command to view already installed libraries. To update a third-party library, use `pip install -U` or `pip install --upgrade`; to remove one, use `pip uninstall`.

### Using Web APIs to Fetch Data

If you want to display weather, traffic, flight, and other information in your own program, you can't provide this information yourself, so you must use web data services. Currently, the vast majority of web data services (also known as web APIs) provide JSON-formatted data based on [HTTP](https://zh.wikipedia.org/wiki/%E8%B6%85%E6%96%87%E6%9C%AC%E4%BC%A0%E8%BE%93%E5%8D%8F%E8%AE%AE) or HTTPS. We can send HTTP requests to specified URLs (Uniform Resource Locators) through Python programs — these URLs are the so-called web APIs. If the request succeeds, it returns an HTTP response, and the message body of the HTTP response contains the JSON-formatted data we need. For more about HTTP, you can read Ruan Yifeng's article [Introduction to HTTP Protocol](http://www.ruanyifeng.com/blog/2016/08/http.html).

There are many websites in China that provide web API interfaces, such as [Juhe Data](https://www.juhe.cn/), [Baidu AI Cloud](https://apis.baidu.com/), etc. These websites offer both free and paid data interfaces. The international [{API}Search](http://apis.io/) website provides similar functionality. The following example demonstrates how to use the [`requests`](http://docs.python-requests.org/zh_CN/latest/) library (a third-party library for accessing web resources via HTTP) to access a web API, retrieve domestic news, and display news titles and links. In this example, we use the domestic news data interface provided by the [Tianapi](https://www.tianapi.com/) website. The API Key (identity identifier) needs to be obtained by registering on the website. After registering on the Tianapi website, an API Key is automatically assigned, but to access the interface and retrieve data, you need to verify your email or phone, and then apply for the interfaces you want to use, as shown in the image below.

<img src="res/20210820151134.png" alt="image-20210820151134034" width="100%">

To access the web via URLs in Python, we recommend using the `requests` third-party library. It is simple and powerful, but needs to be installed separately.

```Bash
pip install requests
```

Fetching domestic news and displaying news titles and links.

```python
import requests

resp = requests.get('http://api.tianapi.com/guonei/?key=APIKey&num=10')
if resp.status_code == 200:
    data_model = resp.json()
    for news in data_model['newslist']:
        print(news['title'])
        print(news['url'])
        print('-' * 60)
```

The code above uses the `get` function from the `requests` module to send a request to Tianapi's domestic news interface. If the request succeeds without issues, the `get` function returns a `Response` object. The `status_code` attribute of this object represents the HTTP response status code. If you don't understand this, just pay attention to the value — if it equals `200` or another value starting with `2`, the request was successful. The `json()` method of the `Response` object can directly convert the returned JSON-formatted data into a Python dictionary, which is very convenient. > **Tip**: The `APIKey` in the code above needs to be replaced with the API Key you applied for on the Tianapi website. The Tianapi website also provides many interesting API interfaces, such as garbage classification, dream interpretation, etc. You can follow the code above to call these interfaces. Each interface has corresponding documentation with detailed instructions on how to use it.

### Summary

Besides using the `json` module, Python can also use the `pickle` and `shelve` modules for serialization and deserialization. However, these two modules use proprietary serialization protocols, so the serialized data can only be recognized by Python. Interested readers can find information about these two modules online. Processing JSON-formatted data is clearly an essential skill for programmers, because whether you are accessing a web API interface or providing one for others to use, you need to have knowledge of handling JSON-formatted data.
