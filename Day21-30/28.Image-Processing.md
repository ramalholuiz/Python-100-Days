## Image Processing

### Basic Concepts

**Color**: Computer systems use RGB (Red, Green, Blue) color model. Each color is represented as (R, G, B) values from 0-255.

Common colors:
- White: (255, 255, 255)
- Black: (0, 0, 0)
- Red: (255, 0, 0)
- Green: (0, 255, 0)
- Blue: (0, 0, 255)
- Yellow: (255, 255, 0)

**Pixel**: The smallest unit of a digital image - a small colored square with specific position and color value.

### Opening and Displaying Images

```python
from PIL import Image

# Open image
image = Image.open('photo.jpg')

# Get image properties
print(f"Format: {image.format}")  # JPEG
print(f"Size: {image.size}")      # (width, height)
print(f"Mode: {image.mode}")      # RGB, RGBA, L, etc.

# Display image
image.show()
```

### Cropping Images

```python
from PIL import Image

image = Image.open('photo.jpg')

# Crop: (left, top, right, bottom)
cropped = image.crop((80, 20, 310, 360))
cropped.show()
```

### Creating Thumbnails

```python
from PIL import Image

image = Image.open('photo.jpg')

# Create thumbnail (modifies in place)
image.thumbnail((128, 128))
image.show()

# Or create without modifying original
image = Image.open('photo.jpg')
image_copy = image.copy()
image_copy.thumbnail((128, 128))
image_copy.show()
```

### Resizing Images

```python
from PIL import Image

image = Image.open('photo.jpg')

# Resize with new dimensions
resized = image.resize((400, 300))
resized.show()
```

### Rotating Images

```python
from PIL import Image

image = Image.open('photo.jpg')

# Rotate counterclockwise
rotated = image.rotate(90)
rotated.show()

# Rotate clockwise
rotated = image.rotate(-90)
rotated.show()
```

### Pasting Images

```python
from PIL import Image

# Load images
background = Image.open('background.jpg')
overlay = Image.open('overlay.png')

# Paste overlay onto background at position (100, 50)
background.paste(overlay, (100, 50))
background.show()

# Save result
background.save('combined.jpg')
```

### Converting Image Modes

```python
from PIL import Image

image = Image.open('photo.jpg')

# Convert to grayscale
gray_image = image.convert('L')
gray_image.show()

# Convert to RGB
rgb_image = image.convert('RGB')
```

### Filtering and Effects

```python
from PIL import Image, ImageFilter

image = Image.open('photo.jpg')

# Blur effect
blurred = image.filter(ImageFilter.BLUR)
blurred.show()

# Edge detection
edges = image.filter(ImageFilter.FIND_EDGES)
edges.show()

# Smoothing
smooth = image.filter(ImageFilter.SMOOTH)
smooth.show()
```

### Batch Processing Images

```python
from PIL import Image
import os

# Process all images in a directory
image_dir = './images'
output_dir = './thumbnails'

if not os.path.exists(output_dir):
    os.makedirs(output_dir)

for filename in os.listdir(image_dir):
    if filename.endswith(('.jpg', '.png', '.jpeg')):
        image_path = os.path.join(image_dir, filename)
        image = Image.open(image_path)
        
        # Create thumbnail
        image.thumbnail((128, 128))
        
        # Save thumbnail
        output_path = os.path.join(output_dir, filename)
        image.save(output_path)
        print(f"Processed: {filename}")
```

### Summary

- Pillow is the primary image processing library
- Use `Image.open()` to load images
- Crop, resize, rotate, and convert images easily
- Apply filters for various effects
- Batch process multiple images for automation
- Combine multiple images by pasting
