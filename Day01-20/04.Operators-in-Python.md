## Operators in Python

The Python language supports many types of operators. The table below lists Python operators in order from highest to lowest precedence. With variables and operators, we can construct various expressions to solve practical problems. In computer science, **an expression is a syntactic entity in a computer program composed of one or more constants, variables, functions, and operators, which a programming language can interpret and evaluate to obtain another value**. It's okay if you don't understand this definition immediately, but you must understand that regardless of what programming language you use, constructing expressions is extremely important.

| Operator | Description |
| --- | --- |
| `[]`, `[:]` | Indexing, slicing |
| `**` | Exponentiation |
| `~`, `+`, `-` | Bitwise NOT, unary plus, unary minus |
| `*`, `/`, `%`, `//` | Multiplication, division, modulo, integer division |
| `+`, `-` | Addition, subtraction |
| `>>`, `<<` | Right shift, left shift |
| `&` | Bitwise AND |
| `^`, `\|` | Bitwise XOR, bitwise OR |
| `<=`, `<`, `>`, `>=` | Less than or equal, less than, greater than, greater than or equal |
| `==`, `!=` | Equal, not equal |
| `is`, `is not` | Identity operators |
| `in`, `not in` | Membership operators |
| `not`, `or`, `and` | Logical operators |
| `=`, `+=`, `-=`, `*=`, `/=`, `%=`, `//=`, `**=`, `&=`, `\|=`, `^=`, `>>=`, `<<=` | Assignment operators |

> **Note**: Operator precedence refers to the order in which operations should be executed when multiple operators appear in an expression. If you're unsure about the precedence of operators in an expression when writing code, you can use parentheses to ensure the execution order.

### Arithmetic Operators

Python has a rich set of arithmetic operators. Besides the most familiar addition, subtraction, multiplication, and division, there are also integer division operators, modulo operators, and exponentiation operators. The following example demonstrates the use of arithmetic operators.

```python
"""
Arithmetic operators

Version: 1.0
Author: Luo Hao
"""
print(321 + 12)     # Addition, outputs 333
print(321 - 12)     # Subtraction, outputs 309
print(321 * 12)     # Multiplication, outputs 3852
print(321 / 12)     # Division, outputs 26.75
print(321 // 12)    # Integer division, outputs 26
print(321 % 12)     # Modulo, outputs 9
print(321 ** 12)    # Exponentiation, outputs 1196906950228928915420617322241
```

Arithmetic operations follow the rule of multiplication and division before addition and subtraction, which is no different from what you learned in mathematics textbooks. In other words, the precedence of multiplication and division is higher than that of addition and subtraction. If there's exponentiation, it has higher precedence than multiplication and division. If you want to change the order of arithmetic operations, you can use parentheses in English input mode. Expressions within parentheses are executed with priority, as shown in the example below.

```python
"""
Precedence of arithmetic operators

Version: 1.0
Author: Luo Hao
"""
print(2 + 3 * 5)           # 17
print((2 + 3) * 5)         # 25
print((2 + 3) * 5 ** 2)    # 125
print(((2 + 3) * 5) ** 2)  # 625
```

### Assignment Operators

The assignment operator is probably the most common operator. Its function is to assign the value on the right to the variable on the left. Assignment operators can also be combined with the arithmetic operators mentioned above to form compound assignment operators. For example, `a += b` is equivalent to `a = a + b`, and `a *= a + 2` is equivalent to `a = a * (a + 2)`. The following example demonstrates the use of assignment and compound assignment operators.

```python
"""
Assignment and compound assignment operators

Version: 1.0
Author: Luo Hao
"""
a = 10
b = 3
a += b        # Equivalent to: a = a + b
a *= a + 2    # Equivalent to: a = a * (a + 2)
print(a)      # Can you calculate what this will output?
```

An expression formed by assignment doesn't produce any value by itself. That is, if you try to put an assignment expression in a `print()` function to output its value, you'll get a syntax error. To solve this problem, Python 3.8 introduced a new assignment operator `:=`, which we call the walrus operator. You might be able to guess why it's called that name. The walrus operator assigns the value on the right side of the operator to the variable on the left, but unlike the regular assignment operator, the value on the right side of the operator is also the value of the entire expression. Look at the code below and you'll understand.

```python
"""
The walrus operator

Version: 1.0
Author: Luo Hao
"""
# SyntaxError: invalid syntax
# print((a = 10))
# Walrus operator
print((a := 10))  # 10
print(a)          # 10
```

> **Tip**: If you don't comment out line 8 above and run the code, you'll see a `SyntaxError: invalid syntax` message. Notice that we added parentheses around `a = 10` in this line. If you accidentally write `print(a = 10)` without parentheses, you'll see a `TypeError: 'a' is an invalid keyword argument for print()` error message. When we discuss functions later, you'll understand what this error message means.

### Comparison Operators and Logical Operators

Comparison operators, also called relational operators, include `==`, `!=`, `<`, `>`, `<=`, `>=`. I'm sure you understand these at first glance. It's important to note that for equality comparison, we use `==` (two equal signs), because `=` is the assignment operator that we just discussed. For inequality comparison, we use `!=`, which is different from the $\neq$ symbol used in mathematics textbooks. In Python 2, `<>` was used to represent inequality, but in Python 3, using `<>` will cause a `SyntaxError`. Comparison operators produce boolean values, which are either `True` or `False`.

Logical operators include three: `and`, `or`, and `not`. `and` literally means "and," so the `and` operator connects two boolean values or expressions that produce boolean values. If both boolean values are `True`, the result is `True`; if either is `False`, the result is `False`. Of course, if the boolean value on the left of the `and` operator is `False`, the result is `False` regardless of what the value on the right is. In this case, the boolean value on the right of the operator is skipped (the technical term is short-circuit evaluation; if the right side of `and` is an expression, that expression won't be executed). `or` literally means "or," so the `or` operator also connects two boolean values or expressions that produce boolean values. If either boolean value is `True`, the result is `True`. Of course, the `or` operator also has short-circuit functionality. When the value on the left is `True`, the value on the right is short-circuited (if the right side of `or` is an expression, that expression won't be executed). The `not` operator can be followed by a boolean value. If the boolean value or expression after `not` is `True`, the result is `False`; if it's `False`, the result is `True`.
