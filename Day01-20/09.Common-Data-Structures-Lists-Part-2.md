## Common Data Structures: Lists - Part 2

### List Methods

List-type variables have many methods that help us manipulate lists. If we have a list named `foos` with a method named `bar`, the syntax for using the method is: `foos.bar()`. This is a syntax for calling an object method through object reference, also called sending a message to an object.

#### Adding and Removing Elements

Lists are mutable containers, meaning we can add elements, remove elements, and modify existing elements. We can use the `append()` method to add elements to the end of a list, or use the `insert()` method to insert elements at a specific position.

```python
languages = ['Python', 'Java', 'C++']
languages.append('JavaScript')
print(languages)  # ['Python', 'Java', 'C++', 'JavaScript']
languages.insert(1, 'SQL')
print(languages)  # ['Python', 'SQL', 'Java', 'C++', 'JavaScript']
```

We can use the `remove()` method to remove an element, the `pop()` method to remove and return an element, or the `clear()` method to empty the list.

```python
languages = ['Python', 'SQL', 'Java', 'C++', 'JavaScript']
if 'Java' in languages:
    languages.remove('Java')
print(languages)  # ['Python', 'SQL', 'C++', 'JavaScript']
languages.pop()   # Remove the last element
print(languages)  # ['Python', 'SQL', 'C++']
languages.clear() # Clear the list
print(languages)  # []
```

#### Finding Position and Count

The `index()` method finds the index position of an element, and the `count()` method counts how many times an element appears.

```python
items = ['Python', 'Java', 'Java', 'C++', 'Kotlin', 'Python']
print(items.index('Python'))  # 0
print(items.count('Python'))  # 2
```

#### Sorting and Reversing

The `sort()` method sorts list elements, and `reverse()` reverses the order.

```python
items = ['Python', 'Java', 'C++', 'Kotlin', 'Swift']
items.sort()
print(items)      # ['C++', 'Java', 'Kotlin', 'Python', 'Swift']
items.reverse()
print(items)      # ['Swift', 'Python', 'Kotlin', 'Java', 'C++']
```

### List Comprehensions

Python offers a special syntax for creating lists called list comprehensions. This syntax is more concise and efficient.

```python
# Create a list of numbers divisible by 3 or 5, from 1 to 99
items = [i for i in range(1, 100) if i % 3 == 0 or i % 5 == 0]
print(items)

# Create a list of squares
nums1 = [35, 12, 97, 64, 55]
nums2 = [num ** 2 for num in nums1]
print(nums2)
```

List comprehensions are not only simpler and more elegant but also more efficient than using loops with `append()`.

### Nested Lists

Lists can contain other lists, creating nested structures useful for representing tables or matrices.

```python
scores = [[95, 83, 92], [80, 75, 82], [92, 97, 90], [80, 78, 69], [65, 66, 89]]
print(scores[0])      # [95, 83, 92]
print(scores[0][1])   # 83
```

### Applications of Lists

Lists are widely used in real-world applications. For example, we can generate random lottery numbers:

```python
"""
Double-color ball random number generator

Author: Luo Hao
Version: 1.1
"""
import random

red_balls = list(range(1, 34))
blue_balls = list(range(1, 17))
# Randomly select 6 red balls
selected_balls = random.sample(red_balls, 6)
selected_balls.sort()
# Output red balls
for ball in selected_balls:
    print(f'{ball:0>2d}', end=' ')
# Randomly select 1 blue ball
blue_ball = random.choice(blue_balls)
# Output blue ball
print(f'{blue_ball:0>2d}')
```
