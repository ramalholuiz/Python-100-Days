## Common Data Structures: Dictionaries

A **dictionary** is a collection of key-value pairs that associates unique keys with corresponding values. Unlike lists that use numeric indices, dictionaries use keys to access values.

### Creating Dictionaries

```python
# Literal syntax
person = {
    'name': 'John Smith',
    'age': 25,
    'height': 178,
    'weight': 60,
    'address': 'Beijing'
}

# Using dict() constructor
person = dict(name='John Smith', age=25, height=178)

# Using dict comprehension
squares = {x: x ** 2 for x in range(1, 6)}
print(squares)  # {1: 1, 2: 4, 3: 9, 4: 16, 5: 25}
```

### Dictionary Operations

#### Membership and Indexing

```python
person = {'name': 'John', 'age': 25, 'height': 178}

# Membership testing
print('name' in person)   # True
print('tel' in person)    # False

# Accessing values
print(person['name'])     # John
person['age'] = 26        # Modify value
person['email'] = 'john@example.com'  # Add new key-value pair
```

**Important**: Dictionary keys must be immutable types (strings, numbers, tuples). Lists and dictionaries cannot be keys.

#### Dictionary Methods

```python
person = {'name': 'John', 'age': 25, 'height': 178}

# get() - safer than indexing
print(person.get('name'))        # John
print(person.get('email'))       # None
print(person.get('email', 'N/A')) # N/A

# keys(), values(), items()
print(person.keys())     # dict_keys(['name', 'age', 'height'])
print(person.values())   # dict_values(['John', 25, 178])
print(person.items())    # dict_items([('name', 'John'), ('age', 25)])

# Iteration
for key, value in person.items():
    print(f'{key}: {value}')
```

### Dictionary Comprehensions

```python
# Create dictionary from two lists
keys = ['a', 'b', 'c']
values = [1, 2, 3]
d = dict(zip(keys, values))
print(d)  # {'a': 1, 'b': 2, 'c': 3}

# Dictionary comprehension
d = {x: x ** 2 for x in range(1, 6)}
print(d)  # {1: 1, 2: 4, 3: 9, 4: 16, 5: 25}
```

### Summary

Dictionaries are ideal for organizing related data with meaningful keys. They provide efficient lookup by key and are essential for modeling real-world objects with multiple attributes.
