### Some Basic Knowledge

Before we systematically start learning Python programming, let's first understand some basic knowledge about computers. A computer's hardware system is usually composed of five major components, including: **the arithmetic unit**, **the control unit**, **storage**, **input devices**, and **output devices**. The arithmetic unit and control unit together form what we commonly call the **Central Processing Unit (CPU)**, whose function is to execute various calculations and control instructions. As mentioned earlier, a program is a collection of instructions. Writing a program means organizing a series of instructions in a certain way and then controlling the computer through these instructions to do what we want. Storage can be divided into **internal storage** and **external storage**. The former is what we commonly call memory, which is the storage space that the CPU can directly address. During the execution of a program, the corresponding data and instructions need to be loaded into memory. Input devices and output devices are often collectively called I/O devices. Keyboards, mice, microphones, and cameras are typical input devices, while displays, printers, and speakers are typical output devices. Currently, most computers we use follow the "Von Neumann architecture," which has two key points: one is **separating storage from the CPU**, and the other is **encoding data in binary form**.

Binary is a counting method of "carrying when reaching two," which is essentially the same as the "carrying when reaching ten" counting method used by humans. Humans use the decimal counting system because we have ten fingers. When we run out of our ten fingers while counting, we can only express larger numbers through carrying. Of course, there are exceptions to everything. The Mayans, probably because they went barefoot for a long time, also used their toes, and thus used a base-20 counting system. Based on this counting method, the Mayan calendar differed from the calendars we commonly use. According to the Mayan calendar, 2012 was the last year of the previous so-called "Sun Age," and 2013 was the beginning of a new "Sun Age." Later, this fact was mistranslated into the absurd claim that "2012 was the end of the world predicted by the Mayans." Today, many people speculate that the slow development of Mayan civilization was related to their use of base-20. For computers, binary is the easiest to implement with physical devices because we can use high voltage to represent 1 and low voltage to represent 0. Not all programmers need to be familiar with binary and the conversion between decimal, binary, octal, and hexadecimal. Most of the time, we can write programs even without this knowledge. However, we must understand that computers use binary counting, and no matter what kind of data it is, when it reaches the computer's memory, it exists in binary form.

We won't go into further detail here. Readers who are unclear about this can research it on their own.

### Variables and Types

To save data in a computer's memory, we first need to understand the concept of variables. In programming languages, **a variable is a carrier of data**. Simply put, it's a block of memory space used to store data. **The value of a variable can be read and modified**, which is the foundation of all calculations and control. There are many types of data that computers can process. The most common is numerical data, but besides numbers, there are also text, images, audio, video, and many other types of data. Although all data in computers exists in binary form, we can use different types of variables to represent differences in data types. The Python language comes with several built-in data types and also allows us to define new data types, which we'll discuss later. First, let's understand several of the most commonly used data types in Python.

1. **Integer type (`int`)**: Python can handle integers of any size and supports binary (e.g., `0b100`, which equals 4 in decimal), octal (e.g., `0o100`, which equals 64 in decimal), decimal (`100`), and hexadecimal (e.g., `0x100`, which equals 256 in decimal) representations. Run the following code and see what it outputs.

    ```python
    print(0b100)  # binary integer
    print(0o100)  # octal integer
    print(100)    # decimal integer
    print(0x100)  # hexadecimal integer
    ```

2. **Float type (`float`)**: A floating-point number is a decimal number. It's called floating-point because, when represented using scientific notation, the decimal point position can vary. Floating-point numbers support both mathematical notation (e.g., `123.456`) and scientific notation (e.g., `1.23456e2`, which represents $1.23456 \times 10^{2}$). Run the following code and see what it outputs.

    ```python
    print(123.456)    # mathematical notation
    print(1.23456e2)  # scientific notation
    ```

3. **String type (`str`)**: A string is any text enclosed in single or double quotes, such as `'hello'` and `"hello"`.

4. **Boolean type (`bool`)**: The boolean type has only two values: `True` and `False`. It can be used to represent "yes" and "no" in the real world, "true" and "false" of propositions, "good" and "bad" of situations, "high" and "low" of levels, etc. If a variable's value has only two states, we can use the boolean type.

### Variable Naming

For each variable, we need to give it a name, just like each person has their own name. In Python, variable naming must follow the following rules and conventions.

**Rules:**
- **Rule 1**: Variable names consist of **letters**, **digits**, and **underscores**, and digits cannot be at the beginning. It should be noted that the letters here refer to Unicode characters. Unicode, called the Universal Code, encompasses most writing systems in the world. This means that Chinese, Japanese, Greek letters, etc., can all be used as characters in variable names, but some special characters (such as `!`, `@`, `#`, etc.) cannot appear in variable names. We strongly recommend that you understand the letters here as **using only English letters as much as possible**.
- **Rule 2**: Python is a **case-sensitive** programming language. Simply put, the uppercase letter `A` and the lowercase letter `a` are two different variables. This is actually not a rule but something everyone should note.
- **Rule 3**: Variable names should **not have the same name as Python keywords** and **should avoid Python reserved words as much as possible**. Keywords here refer to words that have special meanings in Python programs (such as `is`, `if`, `else`, `for`, `while`, `True`, `False`, etc.). Reserved words mainly refer to the names of Python's built-in functions and modules (such as `int`, `print`, `input`, `str`, `math`, `os`, etc.).

**Conventions:**
- **Convention 1**: Variable names usually use **lowercase English letters**, with **multiple words connected by underscores**.
- **Convention 2**: Protected variables start with a single underscore.
- **Convention 3**: Private variables start with two underscores.

You don't need to worry about conventions 2 and 3 for now; they'll become clear as we progress. Of course, as a professional programmer, it's very important to name variables in a way that their purpose is clear from the name. This reflects a programmer's professional demeanor, and many job interviews place great emphasis on this aspect.

### Using Variables

Below, we'll explain variable types and variable usage through examples.

In Python, you can use the `type()` function to check the type of a variable. The concept of a function in programming is very similar to the concept of a function in mathematics. You're probably familiar with mathematical functions, which include a function name, independent variables, and dependent variables. If you don't understand the concept of functions yet, that's okay. We'll explain how to define and use functions in detail later.

```python
"""
Using the type() function to check variable types

Version: 1.0
Author: Luo Hao
"""
a = 100
b = 123.45
c = 'hello, world'
d = True
print(type(a))  # <class 'int'>
print(type(b))  # <class 'float'>
print(type(c))  # <class 'str'>
print(type(d))  # <class 'bool'>
```

You can change a variable's type using Python's built-in functions. Below are some commonly used functions related to variable types.

- `int()`: Converts a number or string to an integer; can specify a base.
- `float()`: Converts a string (when possible) to a floating-point number.
- `str()`: Converts the specified object to a string form; can specify encoding.
- `chr()`: Converts an integer (character code) to the corresponding (single-character) string.
- `ord()`: Converts a (single-character) string to the corresponding integer (character code).
