## Introduction to Object-Oriented Programming

Object-Oriented Programming (OOP) is a paradigm for organizing code around objects rather than functions.

### Objects and Classes

A **class** is a blueprint for creating objects. An **object** is an instance of a class.

```python
class Dog:
    """A simple dog class"""
    
    def __init__(self, name, age):
        """Constructor method"""
        self.name = name
        self.age = age
    
    def bark(self):
        """Dog barks"""
        return f"{self.name} barks: Woof!"
    
    def get_age(self):
        """Get dog's age"""
        return self.age

# Create objects
dog1 = Dog("Buddy", 3)
dog2 = Dog("Max", 5)

# Call methods
print(dog1.bark())       # Buddy barks: Woof!
print(dog2.get_age())    # 5
```

### Class Attributes and Instance Attributes

```python
class Student:
    school = "Example School"  # Class attribute
    
    def __init__(self, name, grade):
        self.name = name        # Instance attribute
        self.grade = grade      # Instance attribute
    
    def study(self):
        return f"{self.name} is studying"

student1 = Student("Alice", "10th")
print(student1.school)  # Example School
print(student1.name)    # Alice
print(student1.study()) # Alice is studying
```

### Special Methods

```python
class Person:
    def __init__(self, name, age):
        self.name = name
        self.age = age
    
    def __str__(self):
        """String representation"""
        return f"Person({self.name}, {self.age})"
    
    def __repr__(self):
        """Developer representation"""
        return f"Person('{self.name}', {self.age})"

person = Person("John", 30)
print(str(person))   # Person(John, 30)
print(repr(person))  # Person('John', 30)
```

### Inheritance

```python
class Animal:
    def __init__(self, name):
        self.name = name
    
    def speak(self):
        return f"{self.name} makes a sound"

class Dog(Animal):
    def speak(self):
        return f"{self.name} barks"

class Cat(Animal):
    def speak(self):
        return f"{self.name} meows"

dog = Dog("Buddy")
cat = Cat("Whiskers")
print(dog.speak())  # Buddy barks
print(cat.speak())  # Whiskers meows
```

### Method Types

```python
class MathUtils:
    value = 0
    
    def __init__(self, x):
        self.x = x
    
    def instance_method(self):
        """Works with instance"""
        return self.x * 2
    
    @classmethod
    def class_method(cls):
        """Works with class"""
        return f"Class method called on {cls.__name__}"
    
    @staticmethod
    def static_method(a, b):
        """Independent function in class"""
        return a + b

obj = MathUtils(5)
print(obj.instance_method())      # 10
print(MathUtils.class_method())   # Class method called on MathUtils
print(MathUtils.static_method(3, 4))  # 7
```

### Summary

Object-Oriented Programming organizes code around objects and classes. Key concepts include:
- Classes and objects
- Attributes and methods
- Inheritance
- Encapsulation
- Special methods

OOP is essential for writing large, maintainable Python applications.
