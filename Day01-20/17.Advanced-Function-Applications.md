## Advanced Function Applications

This lesson covers sophisticated patterns and techniques for function usage.

### Recursion

Recursion is when a function calls itself to solve a problem.

```python
def factorial(n):
    """Calculate factorial using recursion"""
    if n <= 1:
        return 1
    return n * factorial(n - 1)

print(factorial(5))  # 120

def fibonacci(n):
    """Calculate Fibonacci number"""
    if n <= 1:
        return n
    return fibonacci(n - 1) + fibonacci(n - 2)

print(fibonacci(6))  # 8
```

### Decorators

Decorators are functions that modify other functions or classes.

```python
def decorator(func):
    def wrapper():
        print("Before function call")
        func()
        print("After function call")
    return wrapper

@decorator
def hello():
    print("Hello!")

hello()
# Output:
# Before function call
# Hello!
# After function call
```

### Memoization

Cache function results to improve performance.

```python
def memoize(func):
    cache = {}
    def wrapper(n):
        if n not in cache:
            cache[n] = func(n)
        return cache[n]
    return wrapper

@memoize
def fibonacci(n):
    if n <= 1:
        return n
    return fibonacci(n - 1) + fibonacci(n - 2)

print(fibonacci(10))  # Much faster with caching
```

### Callbacks

Passing functions as arguments.

```python
def process_data(data, callback):
    """Process data and apply callback"""
    result = [x * 2 for x in data]
    return callback(result)

def print_result(data):
    print(f"Result: {data}")

process_data([1, 2, 3], print_result)
```

### Function Composition

Combining multiple functions.

```python
def compose(f, g):
    """Compose two functions"""
    return lambda x: f(g(x))

def double(x):
    return x * 2

def add_ten(x):
    return x + 10

# Compose: first add 10, then double
f = compose(double, add_ten)
print(f(5))  # (5 + 10) * 2 = 30
```

### Closures

Functions that capture variables from their enclosing scope.

```python
def make_multiplier(n):
    def multiplier(x):
        return x * n
    return multiplier

times3 = make_multiplier(3)
print(times3(10))  # 30
```
