## Branching Structures

So far, all Python programs we've written execute statements one by one in sequence. This type of code structure is called a sequential structure. However, sequential structure alone cannot solve all problems. For example, if we design a game where the passing condition for level one is for the player to score 1000 points, then after level one is complete, we need to decide whether to proceed to level two or tell the player "Game Over" based on the player's score. In such scenarios, our code will have two branches, and only one will be executed. There are many similar scenarios, and we call this structure a "branching structure" or "selection structure." Take a moment and try to think of at least 5 examples of similar situations!

### Constructing Branching Structures with if and else

In Python, the most commonly used way to construct branching structures is with the `if`, `elif`, and `else` keywords. **Keywords** are words that have special meanings in programming languages. Obviously, you cannot use them as variable names. Of course, we don't use all three keywords every time we construct a branching structure. Let me explain through examples. For instance, let's write a Body Mass Index (BMI) calculator. Body Mass Index, also called BMI, is an internationally used indicator for measuring body weight and health status. The formula is shown below. Generally, $18.5 \le BMI < 24$ is considered normal, $BMI < 18.5$ indicates being underweight, $BMI \ge 24$ indicates being overweight, and $BMI \ge 27$ is considered obese.

$$
BMI = \frac{\text{Weight (kg)}}{\text{Height (m)}^{2}}
$$

> **Note**: In the formula above, weight is in kilograms (kg) and height is in meters (m).

```python
"""
BMI Calculator

Version: 1.0
Author: Luo Hao
"""
height = float(input('Height(cm): '))
weight = float(input('Weight(kg): '))
bmi = weight / (height / 100) ** 2
print(f'{bmi = :.1f}')
if 18.5 <= bmi < 24:
    print('You have a great physique!')
```

> **Tip**: There's a colon (`:`) at the end of the `if` statement, which is entered in English input mode. The special characters in the program, such as `'`, `"`, `=`, `(`, `)`, etc., are all entered in English input mode. This has been mentioned before. Many beginners often overlook this, and when they run the code, they see a lot of error messages. Of course, reading the error messages carefully will make it easy to find what went wrong. However, we **strongly recommend** that you **switch to English input mode** when writing code to avoid unnecessary trouble.

In the code above, after calculating and outputting the BMI, we add a branching structure. If the condition $18.5 \le BMI < 24$ is satisfied, the program outputs "You have a great physique!" But if the condition is not satisfied, this output doesn't appear. This is what we mentioned earlier—code can have different execution paths, and some code may not execute. After the `if` keyword, we provide an expression `18.5 <= bmi < 24`. Earlier, we said that relational operations produce boolean values. If the boolean value after `if` is `True`, then the `print('You have a great physique!')` statement indented with four spaces below the `if` statement will be executed. Let's enter a few sets of data and run the code above.

First set of input:

```
Height(cm): 175
Weight(kg): 68
bmi = 22.2
You have a great physique!
```

Second set of input:

```
Height(cm): 175
Weight(kg): 95
bmi = 31.0
```

Third set of input:

```
Height(cm): 175
Weight(kg): 50
bmi = 16.3
```

Only the height and weight from the first set of input result in a BMI within the 18.5 to 24 range, so the `if` condition is triggered, and the output "You have a great physique!" is displayed. It's worth noting that unlike C, C++, Java, and other programming languages, Python doesn't use curly braces to construct code blocks; instead, it **uses indentation to represent the hierarchical structure of the code**. If multiple statements need to be executed when an `if` condition is true, you just need to keep these statements at the same indentation level. In other words, several consecutive lines of code at the same indentation level belong to the same **code block**, which acts as a single unit for execution. Indentation can use any number of spaces, but **it's standard to use 4 spaces**. We strongly recommend that you **don't use Tab keys for indentation**. If you're already used to doing this, you can set your code editor to automatically convert one Tab into 4 spaces. Many code editors support this feature, and PyCharm has this setting by default. Also, in programming languages like C, C++, and Java, the condition `18.5 <= bmi < 24` would have to be written as two conditions `bmi >= 18.5` and `bmi < 24`, connected with an AND operator. You can write it this way in Python too, for example, the `if` statement above could also be written as `if bmi >= 18.5 and bmi < 24:`, but there's no need to. Isn't the syntax `if 18.5 <= bmi < 24:` more elegant? Below is Java code that does the same thing. It's okay if you don't understand Java code; just observe the difference in syntax between it and Python.

```java
import java.util.Scanner;

class Test {

    public static void main(String[] args) {
        try (Scanner sc = new Scanner(System.in)) {
            System.out.print("Height(cm): ");
            double height = sc.nextDouble();
            System.out.print("Weight(kg): ");
            double weight = sc.nextDouble();
            double bmi = weight / Math.pow(height / 100, 2);
            System.out.printf("bmi = %.1f\n", bmi);
            if (bmi >= 18.5 && bmi < 24) {
                System.out.println("You have a great physique!");
            }
        }
    }
}
```

> **Note**: The above is the Java code for version 1.0 of the BMI calculator. There's a reason why many people prefer Python—it often solves the same problem with less code.

Next, let's modify the code above slightly. When the BMI doesn't satisfy $18.5 \le BMI < 24$, we also provide appropriate feedback. We can add an `else` block after the `if` block, which executes when the condition given by the `if` statement is not met, as shown below. Clearly, only one of the `print('You have a great physique!')` under `if` and the `print('Your physique needs improvement!')` under `else` will be executed.

```python
"""
BMI Calculator

Version: 1.1
Author: Luo Hao
"""
height = float(input('Height(cm): '))
weight = float(input('Weight(kg): '))
bmi = weight / (height / 100) ** 2
print(f'{bmi = :.1f}')
if 18.5 <= bmi < 24:
    print('You have a great physique!')
else:
    print('Your physique needs improvement!')
```
