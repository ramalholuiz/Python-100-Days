## Your First Python Program

In the previous lesson, we learned about the past and present of the Python language and prepared the interpreter environment needed to run Python programs. You're probably eager to start your Python programming journey, but a new question arises: where should we write Python programs, and how do we run them?

### Tools for Writing Code

Below, we'll introduce several tools for writing and running Python code. You can choose the one that best suits your needs. For beginners, I personally recommend PyCharm, as it requires minimal configuration, is very powerful, and is quite beginner-friendly. If you've heard of or prefer PyCharm, feel free to skip the introduction of other tools and jump straight to the PyCharm section.

#### Default Interactive Environment

Open the Windows "Command Prompt" or "PowerShell," type `python`, and press `Enter`. This command takes us into an interactive environment. In an interactive environment, we type a line of code and press `Enter` — the code is immediately executed, and if the code produces a result, it will be displayed in the window, as shown below.

```Bash
Python 3.10.10
Type "help", "copyright", "credits" or "license" for more information.
>>> 2 * 3
6
>>> 2 + 3
5
>>>
```

> **Note**: macOS users need to open the "Terminal" and type `python3` to enter the interactive environment.

To exit the interactive environment, type `quit()`, as shown below.

```Bash
>>> quit()
```

#### A Better Interactive Environment - IPython

The default interactive environment mentioned above doesn't provide a great user experience, as you'll notice when you try it. We can replace it with IPython, which offers more powerful editing and interaction features. You can use Python's package manager `pip` to install IPython from the command prompt or terminal, as shown below.

```bash
pip install ipython
```

> **Tip**: Before installing IPython with the command above, you can change the download source to a domestic mirror using `pip config set global.index-url https://pypi.doubanio.com/simple` or `pip config set global.index-url https://pypi.tuna.tsinghua.edu.cn/simple/` for faster download speeds.

You can then launch IPython with the following command to enter the interactive environment.

```bash
ipython
```

> **Note**: There's also a web-based version of IPython called Jupyter — we'll introduce it when we need it.

### Hello World

By industry convention, the first program we write when learning any programming language outputs `hello, world`. This code was first written by the great Dennis Ritchie (father of C, who co-developed the Unix operating system with Ken Thompson) and Brian Kernighan (inventor of the awk language) in their immortal work *The C Programming Language*. Below is the Python version.

```python
print('hello, world')
```

> **Note**: The parentheses and single quotes in the code above are entered in English input mode. If you accidentally type Chinese parentheses or quotes, you'll see errors like `SyntaxError: invalid character '（' (U+FF08)` or `SyntaxError: invalid character ''' (U+2018)` when running the code.

The code above has only one statement. In this statement, we use a function called `print` that outputs specified content. The `'hello, world'` inside `print`'s parentheses is a string representing text content. In Python, we can use single or double quotes to represent strings. Unlike C, C++, or Java, Python statements don't require semicolons to indicate their end — if we want to write another statement, we simply press Enter for a new line, as shown below. Additionally, Python code doesn't require writing a `main` entry function to run — providing an entry function is a requirement for executable C, C++, or Java code, something many programmers are familiar with, but it's not necessary in Python.

```python
print('hello, world')
print('goodbye, world')
```

Without using an IDE like PyCharm, we can directly call the Python interpreter to run Python programs. We can save the code above as a file named `example01.py`. On Windows, assuming the file is in the `C:\code` directory, open "Command Prompt" or "PowerShell" and enter the following command to run it.

```powershell
python C:\code\example01.py
```

On macOS, assuming our file is in the `/Users/Hao` directory, enter the following command in the Terminal to run the program.

```Bash
python3 /Users/Hao/example01.py
```

> **Tip**: If the path is long and you don't want to type it manually, you can drag and drop the file directly into "Command Prompt" or "Terminal," which will automatically input the full file path.

Try modifying the code above — for example, change the text inside the quotes to something else or write a few more similar statements, and see what results you get. One thing to keep in mind: when writing Python code, it's best to have only one statement per line. Although you can use `;` as a separator to write multiple statements on one line, this makes the code look very ugly and removes good readability.

### Commenting Your Code

Comments are an important part of programming languages, used to explain the purpose of code within the source, thereby enhancing code readability. We can also temporarily disable code segments by adding comments — when you need to use that code again, simply remove the comment markers. In short, **comments make code easier to understand but don't affect execution results**.

There are two forms of comments in Python:

1. Single-line comments: Start with `#` and a space, commenting out everything from `#` to the end of the line.
2. Multi-line comments: Start with three quotes (usually double quotes) and end with three quotes, typically used for adding multi-line explanatory content.

```python
"""
First Python Program - hello, world

Version: 1.0
Author: Luo Hao
"""
# print('hello, world')
print("Hello, World!")
```
