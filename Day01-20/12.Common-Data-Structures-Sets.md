## Common Data Structures: Sets

A **set** is a collection of unordered, unique, and well-defined elements. Sets in Python follow three key properties:

1. **Unordered**: Elements have no specific order and cannot be accessed by indexing.
2. **Uniqueness**: No duplicate elements; each element appears only once.
3. **Definiteness**: An element either belongs to the set or doesn't.

**Sets have superior performance for membership testing compared to lists** due to their underlying hash-based storage.

### Creating Sets

```python
# Using literal syntax
set1 = {1, 2, 3, 3, 3, 2}
print(set1)  # {1, 2, 3}

# Using set() constructor
set2 = set([1, 2, 2, 3, 3])
print(set2)  # {1, 2, 3}

# Empty set
set3 = set()
print(set3)  # set()

# Using set comprehension
set4 = {num for num in range(1, 20) if num % 3 == 0 or num % 7 == 0}
print(set4)
```

**Important**: Set elements must be hashable (immutable) types. Lists, sets, and dictionaries cannot be set elements.

### Set Operations

#### Membership Testing

```python
set1 = {1, 2, 3, 4, 5}
print(2 in set1)      # True
print(10 not in set1) # True
```

#### Set Operations

```python
set1 = {1, 2, 3, 4, 5}
set2 = {2, 4, 6, 8, 10}

# Intersection (共同元素)
print(set1 & set2)              # {2, 4}
print(set1.intersection(set2))  # {2, 4}

# Union (合并)
print(set1 | set2)        # {1, 2, 3, 4, 5, 6, 8, 10}
print(set1.union(set2))   # {1, 2, 3, 4, 5, 6, 8, 10}

# Difference (差集)
print(set1 - set2)            # {1, 3, 5}
print(set1.difference(set2))  # {1, 3, 5}

# Symmetric Difference (对称差)
print(set1 ^ set2)                    # {1, 3, 5, 6, 8, 10}
print(set1.symmetric_difference(set2))
```

#### Set Comparison

```python
set1 = {1, 3, 5}
set2 = {1, 2, 3, 4, 5}

print(set1 < set2)        # True (proper subset)
print(set1 <= set2)       # True (subset)
print(set2 > set1)        # True (superset)
print(set1.issubset(set2))    # True
print(set2.issuperset(set1))  # True
```

### Set Methods

```python
set1 = {1, 10, 100}

# Add element
set1.add(1000)
print(set1)  # {1, 10, 100, 1000}

# Remove element
set1.discard(10)
set1.remove(100)  # Raises KeyError if not found
print(set1)
```

### Summary

Sets are useful for storing unique elements and performing mathematical set operations. They're particularly efficient for membership testing and eliminating duplicates from sequences.
