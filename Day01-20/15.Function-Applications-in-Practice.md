## Function Applications in Practice

This lesson focuses on practical applications of functions through real-world examples.

### Example 1: Perfect Numbers

A perfect number is a positive integer that equals the sum of its proper divisors (excluding itself). For example, 6 = 1 + 2 + 3.

```python
def is_perfect(num):
    """Check if a number is perfect"""
    sum_divisors = 0
    for i in range(1, num):
        if num % i == 0:
            sum_divisors += i
    return sum_divisors == num

# Find all perfect numbers up to 10000
for n in range(1, 10001):
    if is_perfect(n):
        print(n)  # Outputs: 6, 28, 496, 8128
```

### Example 2: Palindrome Numbers

A palindrome number reads the same forwards and backwards.

```python
def is_palindrome(num):
    """Check if a number is a palindrome"""
    s = str(num)
    return s == s[::-1]

# Check various numbers
print(is_palindrome(121))    # True
print(is_palindrome(123))    # False
print(is_palindrome(12321))  # True
```

### Example 3: Flower Numbers

Narcissistic numbers (Armstrong numbers) are numbers that equal the sum of their digits raised to the power of the number of digits.

```python
def is_narcissistic(num):
    """Check if a number is narcissistic (Armstrong number)"""
    digits = [int(d) for d in str(num)]
    n = len(digits)
    return sum(d ** n for d in digits) == num

# Examples
print(is_narcissistic(153))    # True (1³ + 5³ + 3³ = 153)
print(is_narcissistic(1634))   # True (1⁴ + 6⁴ + 3⁴ + 4⁴ = 1634)
```

### Example 4: Prime Numbers

A prime number is only divisible by 1 and itself.

```python
def is_prime(num):
    """Check if a number is prime"""
    if num < 2:
        return False
    for i in range(2, int(num ** 0.5) + 1):
        if num % i == 0:
            return False
    return True

# Find primes up to 100
primes = [n for n in range(2, 101) if is_prime(n)]
print(len(primes))  # 25 primes
```

### Example 5: Reverse Number

Reverse the digits of a number.

```python
def reverse_number(num):
    """Reverse the digits of a number"""
    return int(str(num)[::-1])

print(reverse_number(12345))  # 54321
print(reverse_number(1000))   # 1
```

### Example 6: GCD and LCM

Greatest Common Divisor and Least Common Multiple.

```python
def gcd(a, b):
    """Calculate GCD using Euclidean algorithm"""
    while b:
        a, b = b, a % b
    return a

def lcm(a, b):
    """Calculate LCM"""
    return a * b // gcd(a, b)

print(gcd(12, 18))   # 6
print(lcm(12, 18))   # 36
```
