## Loop Structures

When writing programs, we often encounter situations where we need to repeatedly execute certain instructions. For example, we might need to output "hello, world" to the screen every second and continue for one hour. The code below can accomplish this operation once. If we wanted to continue for an hour, we'd need to write this code 3600 times. Would you be willing to do that?

```python
import time

print('hello, world')
time.sleep(1)
```

> **Note**: Python's built-in `time` module's `sleep()` function can pause program execution. The parameter `1` represents the number of seconds to sleep, and can be an `int` or `float` (e.g., `0.05` represents 50 milliseconds). We'll explain more about functions and modules in later lessons.

To address the problems in the scenario above, we can use loop structures in Python programs. A loop structure is code that controls certain instructions to be executed repeatedly. With such structures, the code above doesn't need to be written 3600 times; we just write it once and place it in a loop structure to repeat 3600 times. In Python, there are two ways to construct loop structures: `for-in` loops and `while` loops.

### for-in Loops

If we know exactly how many times the loop should execute, we recommend using a `for-in` loop. For example, in the scenario mentioned above where we need to repeat 3600 times, we can use the following code to implement it. Notice that the code block controlled by a `for-in` loop is also constructed through indentation, which is the same way we constructed code blocks in branching structures. The code block controlled by a `for-in` loop is called the loop body. Usually, statements in the loop body will be executed repeatedly according to the loop settings.

```python
"""
Output "hello, world" every 1 second for 1 hour

Author: Luo Hao
Version: 1.0
"""
import time

for i in range(3600):
    print('hello, world')
    time.sleep(1)
```

The `range(3600)` in the code above creates a range from `0` to `3599`. When we put such a range in a `for-in` loop, the loop variable `i` will successively take values from `0` to `3599`, which causes the statements in the `for-in` code block to execute 3600 times. Of course, the `range` function is very flexible. Here are examples of using it:

- `range(101)`: Generates integers from `0` to `100` (note: 101 is not included).
- `range(1, 101)`: Generates integers from `1` to `100`, which is left-closed, right-open: $[1, 101)$.
- `range(1, 101, 2)`: Generates odd numbers from `1` to `100`, where `2` is the step size (increment), and 101 is not included.
- `range(100, 0, -2)`: Generates even numbers from `100` to `1`, where `-2` is the step size (decrement), and 0 is not included.

You may have noticed that the output and sleep operations in the code above don't use the loop variable `i`. For `for-in` loops where the loop variable is not needed, following Python conventions, we usually name the loop variable `_`. The modified code is as follows. Although the output doesn't change, this style shows you're more professional and raises your coding credibility.

```python
"""
Output "hello, world" every 1 second for 1 hour

Author: Luo Hao
Version: 1.1
"""
import time

for _ in range(3600):
    print('hello, world')
    time.sleep(1)
```

The code above takes one hour to execute. If you want to end the program early, in PyCharm you can click the stop button on the run window. If running code in a command prompt or terminal, you can use `Ctrl+C` to terminate the program.

Below, we use a `for-in` loop to calculate the sum of integers from 1 to 100, i.e., $\sum_{n=1}^{100}{n}$.

```python
"""
Sum of integers from 1 to 100

Version: 1.0
Author: Luo Hao
"""
total = 0
for i in range(1, 101):
    total += i
print(total)
```

In the code above, the variable `total` stores the result of accumulation. During the loop, the loop variable `i` takes values from 1 to 100. For each value of `i`, we execute `total += i`, which is equivalent to `total = total + i`, implementing the accumulation operation. When the loop ends, we output the value of `total`, which is 5050, the sum of integers from 1 to 100. Note that `print(total)` is not indented and is not controlled by the `for-in` loop, so it won't be executed repeatedly.

Let's write another program to sum the even numbers from 1 to 100, as shown below.

```python
"""
Sum of even numbers from 1 to 100

Version: 1.0
Author: Luo Hao
"""
total = 0
for i in range(1, 101):
    if i % 2 == 0:
        total += i
print(total)
```

> **Note**: In the `for-in` loop above, we use a branching structure to check if the loop variable `i` is even.

We can also modify the `range` function's parameters, changing the start and step to `2`, to sum even numbers from 1 to 100 with simpler code.

```python
"""
Sum of even numbers from 1 to 100

Version: 1.1
Author: Luo Hao
"""
total = 0
for i in range(2, 101, 2):
    total += i
print(total)
```

Of course, an even simpler approach is to use Python's built-in `sum()` function, which lets us skip the loop structure entirely.

```python
"""
Sum of even numbers from 1 to 100

Version: 1.2
Author: Luo Hao
"""
print(sum(range(2, 101, 2)))
```

### while Loops

If we need to construct a loop but can't determine how many times it should repeat, we recommend using a `while` loop. A `while` loop uses a boolean value or an expression that produces a boolean value to control the loop. When the boolean value or expression is `True`, the statements in the loop body (the code block indented below the `while` statement) are executed repeatedly. When the value is `False`, the loop ends.

Below, we use a `while` loop to sum integers from 1 to 100.

```python
"""
Sum of integers from 1 to 100

Version: 1.1
Author: Luo Hao
"""
total = 0
i = 1
while i <= 100:
    total += i
    i += 1
print(total)
```

Compared to the `for-in` loop, the code above adds a variable `i` before the loop starts. We use this variable to control the loop, so the condition `i <= 100` follows the `while` keyword. In the `while` loop body, besides accumulation, we need to increment the value of `i`, so we add the statement `i += 1`. This way, `i` takes values 1, 2, 3, ..., until it becomes 101. When `i` becomes 101, the `while` loop condition is no longer true, and the code exits the loop. At this point, we output the value of `total`, which is 5050, the sum from 1 to 100.

To sum even numbers from 1 to 100, we can slightly modify the code above.

```python
"""
Sum of even numbers from 1 to 100

Version: 1.3
Author: Luo Hao
"""
total = 0
i = 2
while i <= 100:
    total += i
    i += 2
print(total)
```

### break and continue

What happens if we set the `while` loop condition to `True`, making the condition always true? Look at the code below, which still uses `while` to construct a loop that calculates the sum of even numbers from 1 to 100.

```python
"""
Sum of even numbers from 1 to 100

Version: 1.4
Author: Luo Hao
"""
total = 0
i = 2
while True:
    total += i
    i += 2
    if i > 100:
        break
print(total)
```

In the code above, `while True` creates a loop where the condition is always true, meaning the loop won't end without special handling. This is what we call an "infinite loop." To stop the loop when `i` exceeds 100, we use the `break` keyword, which terminates the execution of the loop structure. Note that `break` only terminates the loop it's in, which is important when using nested loops (we'll cover nested loops later). Besides `break`, there's another keyword `continue` that can be used in loop structures. It allows you to skip the rest of the loop body and proceed directly to the next iteration, as shown below.

```python
"""
Sum of even numbers from 1 to 100

Version: 1.5
Author: Luo Hao
"""
total = 0
for i in range(1, 101):
    if i % 2 != 0:
        continue
    total += i
print(total)
```

> **Note**: The code above uses the `continue` keyword to skip cases where `i` is odd. Only when `i` is even do we execute `total += i`.

### Nested Loop Structures

Like branching structures, loop structures can also be nested. That is, you can have a loop structure within a loop structure. The example below shows how to use nested loops to output a multiplication table (times table).

```python
"""
Print multiplication table

Version: 1.0
Author: Luo Hao
"""
for i in range(1, 10):
    for j in range(1, i + 1):
        print(f'{i}×{j}={i * j}', end='\t')
    print()
```

In the code above, the loop body of the outer `for-in` loop contains another `for-in` loop. The outer loop controls the number of rows of output, while the inner loop controls the number of columns in each row. The output of the inner `for-in` loop is one complete row of the multiplication table. When the inner loop finishes, we use `print()` to create a line break, moving subsequent output to a new line. The final output is shown below.

### Applications of Loop Structures

#### Example 1: Prime Number Detection

**Requirement**: Input a positive integer greater than 1 and determine whether it's a prime number.

> **Hint**: A prime number is an integer greater than 1 that can only be divided by 1 and itself. For example, for a positive integer $n$, we can search for factors of $n$ between 2 and $n - 1$ to determine if it's prime. Of course, the loop doesn't need to start from 2 and go all the way to $n - 1$, because for integers greater than 1, factors appear in pairs, so we only need to loop up to $\sqrt{n}$.

```python
"""
Input a positive integer greater than 1 and determine if it's a prime number

Version: 1.0
Author: Luo Hao
"""
num = int(input('Please enter a positive integer: '))
end = int(num ** 0.5)
is_prime = True
for i in range(2, end + 1):
    if num % i == 0:
        is_prime = False
        break
if is_prime:
    print(f'{num} is a prime number')
else:
    print(f'{num} is not a prime number')
```

> **Note**: In the code above, we use a boolean variable `is_prime`. We initially set it to `True`, assuming `num` is a prime number. Next, we search for factors of `num` in the range from 2 to $\sqrt{num}$. If we find a factor, then it's not a prime number. We set `is_prime` to `False` and use the `break` keyword to terminate the loop. Finally, based on whether `is_prime` is `True` or `False`, we provide different output.

#### Example 2: Greatest Common Divisor

**Requirement**: Input two positive integers and find their greatest common divisor.

> **Hint**: The greatest common divisor of two numbers is the largest common factor of the two numbers.

```python
"""
Input two positive integers and find their greatest common divisor

Version: 1.0
Author: Luo Hao
"""
x = int(input('x = '))
y = int(input('y = '))
for i in range(x, 0, -1):
    if x % i == 0 and y % i == 0:
        print(f'Greatest common divisor: {i}')
        break
```

> **Note**: The loop variable in the `for-in` loop above takes values from large to small. The first factor `i` we find that divides both `x` and `y` evenly is the greatest common divisor. At that point, we use `break` to terminate the loop. If `x` and `y` are coprime, the loop will execute until `i` becomes 1, since 1 is a factor of all positive integers. In this case, the greatest common divisor of `x` and `y` is 1.

The above code has efficiency problems. If `x` is `999999999998` and `y` is `999999999999`, it's clear the two numbers are coprime and the GCD is 1. However, with the above code, the loop would repeat 999999999998 times, which is usually unacceptable. We can use the Euclidean algorithm to find the GCD more efficiently, as shown below.

```python
"""
Input two positive integers and find their greatest common divisor

Version: 1.1
Author: Luo Hao
"""
x = int(input('x = '))
y = int(input('y = '))
while y % x != 0:
    x, y = y % x, x
print(f'Greatest common divisor: {x}')
```

> **Note**: A method and steps to solve a problem can be called an algorithm. For the same problem, we can design different algorithms, and different algorithms will have differences in space usage and execution efficiency. These differences represent the quality of the algorithm. Compare the two code segments above and understand why we say the Euclidean algorithm is a better choice. In the code above, `x, y = y % x, x` means assigning the value of `y % x` to `x` and the original value of `x` to `y`.

#### Example 3: Number Guessing Game

**Requirement**: The computer generates a random number between 1 and 100. The player inputs their guess. The computer provides appropriate feedback ("too high," "too low," or "correct"). If the player guesses the number, the computer tells them how many attempts it took, and the game ends. Otherwise, the game continues.

```python
"""
Number guessing game

Version: 1.0
Author: Luo Hao
"""
import random

answer = random.randrange(1, 101)
counter = 0
while True:
    counter += 1
    num = int(input('Please enter: '))
    if num < answer:
        print('Too low.')
    elif num > answer:
        print('Too high.')
    else:
        print('Correct!')
        break
print(f'You guessed {counter} times in total.')
```

> **Note**: The code above uses `import random` to import the `random` module from Python's standard library. The `randrange` function in this module generates a random number between 1 and 100 (not including 100). The variable `counter` records how many times the loop executes, which is how many guesses the user made. Each loop iteration increments `counter` by 1.

### Summary

Now that we've learned about branching and loop structures in Python, we can solve many practical problems. Through this lesson, you should know that we can use `for` and `while` keywords to construct loop structures. **If we know the number of loop iterations beforehand, we usually use `for` loops**. **If the number of iterations cannot be determined, we can use `while` loops**. Additionally, we can **use `break` to terminate a loop** and **use the `continue` keyword to skip to the next iteration**.
