## Functions and Modules

Functions are one of the most important concepts in programming. They allow us to encapsulate reusable code and avoid repetition.

### Defining Functions

In Python, we use the `def` keyword to define functions:

```python
def factorial(n):
    """Calculate the factorial of n"""
    result = 1
    for num in range(2, n + 1):
        result *= num
    return result

# Calling the function
print(factorial(5))  # 120
```

A function definition includes:
- **Function name**: What we call the function
- **Parameters**: Input values
- **Return value**: Output value(s)
- **Docstring**: Documentation (optional but recommended)

### Function Parameters

#### Positional Parameters

```python
def is_triangle(a, b, c):
    """Check if three sides can form a triangle"""
    return a + b > c and b + c > a and a + c > b

print(is_triangle(1, 2, 3))  # False
print(is_triangle(4, 5, 6))  # True
```

#### Keyword Parameters

```python
# Arguments can be passed by name
print(is_triangle(c=3, b=2, a=1))  # False
print(is_triangle(a=5, c=6, b=4))  # True
```

#### Default Parameters

```python
def greet(name, greeting='Hello'):
    print(f'{greeting}, {name}!')

greet('Alice')              # Hello, Alice!
greet('Bob', 'Hi')          # Hi, Bob!
greet('Charlie', greeting='Hey')  # Hey, Charlie!
```

#### Variable-length Parameters

```python
def sum_all(*numbers):
    """Sum any number of arguments"""
    total = 0
    for num in numbers:
        total += num
    return total

print(sum_all(1, 2, 3))        # 6
print(sum_all(1, 2, 3, 4, 5))  # 15
```

### Using Modules

Python provides a vast standard library with pre-built functions:

```python
import math
print(math.factorial(5))  # 120

# Importing specific functions
from math import factorial as fac
print(fac(5))  # 120

# Importing all functions
from math import *
print(sqrt(16))  # 4.0
```

### Common Built-in Functions

```python
# Type conversion
print(int('123'))       # 123
print(float('3.14'))    # 3.14
print(str(123))         # '123'

# Getting length
print(len([1, 2, 3]))   # 3
print(len('hello'))     # 5

# Min/Max
print(min(1, 2, 3))     # 1
print(max(1, 2, 3))     # 3

# Sum
print(sum([1, 2, 3]))   # 6

# Range
print(list(range(5)))   # [0, 1, 2, 3, 4]
```

### Summary

**Functions are essential for writing clean, reusable, maintainable code**. They help you:
- Avoid code repetition
- Organize code logically
- Make code more readable
- Facilitate testing and debugging

Always prefer using existing functions from the standard library or third-party modules rather than reinventing the wheel.
