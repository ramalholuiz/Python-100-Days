## Introduction to Python

### A Brief Introduction to Python

Python (British pronunciation: /ˈpaɪθən/; American pronunciation: /ˈpaɪθɑːn/) is a programming language invented by the Dutch programmer Guido von Rossum. It is currently the most popular and widely-used programming language in the world. Python emphasizes code readability and syntactic simplicity. Compared to other influential programming languages like C, C++, and Java, Python allows users to express their intentions with less code. #### Python Timeline

Here are some important milestones in the development of Python:

1. December 1989: Guido van Rossum decided to develop a new scripting language and its interpreter to pass the time during a boring Christmas. The new language would serve as a successor to the ABC language, primarily used to replace Unix shell and C for system administration. Being a big fan of the BBC TV show *Monty Python's Flying Circus*, he chose "Python" as the name for the new language.
2. February 1991: Guido van Rossum posted the initial code of the Python interpreter on the alt.sources newsgroup, marked as version 0.9.0.
3. January 1994: Python 1.0 was released — where the dream began.
4. October 2000: Python 2.0 was released. The entire development process became more transparent, and the ecosystem began to take shape.
5. December 2008: Python 3.0 was released, introducing many modern programming language features, but it was not fully backward-compatible.
6. April 2011: pip was first released, giving Python its own package management tool.
7. July 2018: Guido van Rossum announced he was taking a "permanent vacation" from his role as "Benevolent Dictator for Life" (the person with final decision-making authority when disputes arise in open-source project communities).
8. January 2020: After Python 2 and Python 3 coexisted for 11 years, official support for Python 2 was discontinued, with the hope that users would switch to Python 3 as soon as possible.
9. Currently: Python is widely used in large language models (GPT-3, GPT-4, BERT, etc.), computer vision (image recognition, object detection, image generation, etc.), intelligent recommendations (YouTube, Netflix, ByteDance, etc.), autonomous driving (Waymo, Apollo, etc.), speech recognition, data science, quantitative trading, automated testing, DevOps automation, and many other fields. Python's ecosystem is thriving.

> **Note**: Most software version numbers are divided into three segments in the form A.B.C, where A represents the major version number (incremented only when the software undergoes a complete rewrite or introduces backward-incompatible changes); B represents feature updates (incremented when new features are added); and C represents minor changes (e.g., bug fixes), incremented with every modification.

#### Pros and Cons of Python

Python has many advantages. Here are a few:

1. **Simple and elegant** — compared to many other programming languages, Python is **easier to learn**.
2. You can do more with less code, **improving development efficiency**.
3. Open source, with a **strong community and ecosystem**.
4. **Extremely versatile**, with strong adaptability.
5. A **glue language** that can integrate components developed in other languages.
6. An interpreted language that is easier to run **cross-platform**, working on multiple operating systems.

Python's main disadvantage is **lower execution efficiency** (a common issue with interpreted languages). If execution efficiency is your top priority, C, C++, or Go may be better choices.

### Installing the Python Environment

As the saying goes, "A craftsman must first sharpen his tools." To begin your Python programming journey, you first need to install the Python environment on your computer — simply put, you need to install the Python interpreter required to run Python programs. We recommend installing the official Python 3 interpreter, which is written in C and commonly referred to as CPython. It is probably your best choice right now. First, go to the official website's [download page](https://www.python.org/downloads/) and click the "Download" button to enter the download page, where you'll need to select the appropriate Python 3 installer for your operating system, as shown below.

<img src="res/day01/python_download_page_1.png" style="zoom:40%;">

On the download page, some Python versions don't provide installers for Windows and macOS — only source code archives. For those familiar with Linux, you can build and install from source. For Windows or macOS users, we **strongly recommend** using the installer. For example, if you want to install Python 3.10, selecting Python 3.10.10 or Python 3.10.11 will provide Windows or macOS installers, while other versions may only have source code, as shown below.

#### Windows Environment

Below, we'll use Windows 11 as an example to explain how to install the Python environment on Windows. Double-click the installer downloaded from the official website to open the installation wizard, as shown below.

<img src="res/day01/install_python_1.png" style="zoom:50%;">

First, be sure to check the "Add python.exe to PATH" option, which will add the Python interpreter to the Windows system PATH environment variable (don't worry if you don't understand this — just check it). Second, "Use admin privileges when installing py.exe" is for obtaining administrator privileges during installation — it's recommended to check this as well. Then, select "Customize Installation" for a custom installation mode — this is the professional's choice, and you are (pretending to be) that professional. Using "Install Now" (default installation) is not recommended.

Next, the installation wizard will prompt you to select "Optional Features." You can select all of them here. Worth mentioning is the second item — pip, Python's package management tool that helps you install third-party libraries and tools. Make sure to check it, then click "Next" to proceed.

<img src="res/day01/install_python_2.png" style="zoom:50%;">

Next is the "Advanced Options" selection. We recommend checking only "Add Python to environment variables" and "Precompile standard library." The former automatically configures environment variables, and the latter precompiles the standard library (generating `.pyc` files) so there's no need for on-the-fly compilation. Again, don't worry if you don't understand — just check them. The "Customize install location" path is **strongly recommended** to be changed to a custom path that should not contain Chinese characters, spaces, or other special characters. Paying attention to this will save you a lot of unnecessary trouble in the future. Once configured, click "Install" to begin installation.

<img src="res/day01/install_python_3.png" style="zoom:50%;">

A successful installation will display the screen shown below. The keyword for success is "successful" — if the installation fails, this word will change to "failed."

<img src="res/day01/install_python_4.png" style="zoom:50%;">

After installation, you can open the Windows "Command Prompt" or PowerShell and type `python --version` or `python -V` to check if the installation was successful — this command shows the Python interpreter version number. If you see a screen like the one below, congratulations — the Python environment has been successfully installed. We also recommend checking whether Python's package management tool pip is available using `pip --version` or `pip -V`.

#### Other Installation Methods

Some people might recommend that beginners install [Anaconda](https://www.anaconda.com/download/success) directly, as Anaconda will install the Python interpreter along with some commonly used third-party libraries and provides some convenient tools — especially suitable for complete beginners. Personally, I don't recommend this approach because installing Anaconda will install a large number of third-party libraries (taking up significant disk space) whether you need them or not, and your terminal or command prompt will be hijacked by Anaconda (automatically activating a virtual environment on startup). This doesn't conform to the software design **Principle of Least Astonishment**. Other minor issues with Anaconda won't be discussed here — if you insist on using Anaconda, I recommend installing Miniconda, which is on the same download page.

Beginners often say, "I want to write Python programs — can't I just install PyCharm?" Here's a quick explanation: PyCharm is just a tool that assists in writing Python code. It doesn't have the ability to run Python code on its own — running Python code relies on the Python interpreter we installed above. Of course, some PyCharm versions will prompt you to download the Python interpreter online when creating a Python project if they can't detect a Python environment on your computer. We'll cover PyCharm installation and usage in the next lesson.

### Summary

Let's summarize what we've learned:

1. Python is a powerful language that can do many things, making it well worth learning.
2. To use Python, you first need to install the Python environment — that is, the Python interpreter required to run Python programs.
3. On Windows, you can type `python --version` in the Command Prompt or PowerShell to check if the Python environment was installed successfully. On macOS, you can type `python3 --version` in the Terminal to check.
