## Advanced Function Usage

This lesson covers more sophisticated function concepts.

### Local and Global Variables

```python
global_var = 100

def my_function():
    local_var = 50
    print(f"Local: {local_var}, Global: {global_var}")

my_function()  # Local: 50, Global: 100
# print(local_var)  # Error - local_var not defined outside function
```

### Variable Scope

Variables defined inside a function are local to that function. Variables defined outside are global.

```python
x = 10

def func1():
    x = 20
    print(x)  # 20

def func2():
    print(x)  # 10

func1()  # Prints 20
func2()  # Prints 10
print(x) # Prints 10
```

### The global Keyword

```python
counter = 0

def increment():
    global counter
    counter += 1

increment()
increment()
print(counter)  # 2
```

### Anonymous Functions (Lambda)

Lambda functions are small anonymous functions defined with `lambda`.

```python
# Regular function
def add(a, b):
    return a + b

# Equivalent lambda
add = lambda a, b: a + b
print(add(2, 3))  # 5

# Using lambda with map, filter, sort
numbers = [1, 2, 3, 4, 5]
squared = list(map(lambda x: x ** 2, numbers))
print(squared)  # [1, 4, 9, 16, 25]

even = list(filter(lambda x: x % 2 == 0, numbers))
print(even)  # [2, 4]
```

### Higher-Order Functions

Functions that accept or return other functions.

```python
def apply_twice(func, x):
    """Apply function twice"""
    return func(func(x))

def double(x):
    return x * 2

print(apply_twice(double, 3))  # 12
```

### Docstrings and Type Hints

```python
def greet(name: str) -> str:
    """
    Greet a person by name.
    
    Args:
        name: The person's name
    
    Returns:
        A greeting message
    """
    return f"Hello, {name}!"

print(greet("Alice"))
```

### Summary

Advanced function techniques enable writing more flexible and powerful code. Understanding scope, lambda functions, and higher-order functions expands your programming capabilities.
