## Common Data Structures: Strings

### String Definition

A **string** is a finite sequence of zero or more characters. In Python, we represent a string by enclosing characters in single or double quotes.

```python
s1 = 'hello, world!'
s2 = "你好，世界！❤️"
s3 = '''hello,
wonderful
world!'''
```

#### Escape Characters

We use backslash (`\`) to escape special characters. For example, `\n` represents a newline, `\t` represents a tab.

```python
s1 = '\'hello, world!\''  # String with single quotes
s2 = '\\hello, world!\\'  # String with backslashes
print(s1)
print(s2)
```

#### Raw Strings

Raw strings (prefixed with `r` or `R`) treat backslashes literally.

```python
s1 = '\it \is \time'
s2 = r'\it \is \time'
print(s1)  # Different output due to escape sequences
print(s2)  # Literal backslashes
```

### String Operations

#### Concatenation and Repetition

```python
s1 = 'hello' + ', ' + 'world'
print(s1)    # hello, world
s2 = '!' * 3
print(s2)    # !!!
```

#### Comparison Operations

```python
s1 = 'a whole new world'
s2 = 'hello world'
print(s1 == s2)             # False
print(s1 < s2)              # True
print('wo' in s1)           # True
```

#### Length

```python
s = 'hello, world'
print(len(s))               # 12
```

#### Indexing and Slicing

```python
s = 'abc123456'
print(s[0], s[-1])          # a 6
print(s[2:5])               # c12
print(s[::2])               # ac246
print(s[::-1])              # 654321cba
```

**Important**: Strings are immutable, so you cannot modify characters using indexing.

### String Traversal

```python
s = 'hello'
for char in s:
    print(char)
```

### String Methods

#### Case Conversion

```python
s1 = 'hello, world!'
print(s1.capitalize())  # Hello, world!
print(s1.upper())       # HELLO, WORLD!
print(s1.lower())       # hello, world!
print(s1.title())       # Hello, World!
```

#### Finding Substrings

```python
s = 'hello, world'
print(s.find('o'))      # 4 (first occurrence)
print(s.find('o', 5))   # 8 (search from position 5)
print(s.index('o'))     # 4
print('o' in s)         # True
```

#### Splitting and Joining

```python
s = 'python, java, c++'
items = s.split(', ')
print(items)            # ['python', 'java', 'c++']
print(', '.join(items)) # python, java, c++
```

#### Stripping Whitespace

```python
s = '  hello, world!  '
print(s.strip())        # hello, world!
print(s.lstrip())       # hello, world!  
print(s.rstrip())       #   hello, world!
```

#### Replacing Substrings

```python
s = 'hello, world'
print(s.replace('world', 'python'))  # hello, python
```

### Summary

Strings are fundamental data types in Python for handling text. They support many operations and methods for manipulation. **Strings are immutable**, so operations create new strings rather than modifying the original. Understanding string operations is crucial for effective Python programming.
