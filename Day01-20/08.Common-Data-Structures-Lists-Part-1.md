## Common Data Structures: Lists - Part 1

Before we begin this lesson, let's give you a programming assignment: roll a single die 6000 times and count how many times each number appears. This task should be quite straightforward. We can use random numbers uniformly distributed from 1 to 6 to simulate rolling a die, then use 6 variables to separately record how many times each number appears. Based on what we've learned, you should be able to write the code below without much difficulty.

```python
"""
Roll a single die 6000 times and count occurrences of each face

Author: Luo Hao
Version: 1.0
"""
import random

f1 = 0
f2 = 0
f3 = 0
f4 = 0
f5 = 0
f6 = 0
for _ in range(6000):
    face = random.randrange(1, 7)
    if face == 1:
        f1 += 1
    elif face == 2:
        f2 += 1
    elif face == 3:
        f3 += 1
    elif face == 4:
        f4 += 1
    elif face == 5:
        f5 += 1
    else:
        f6 += 1
print(f'1 appeared {f1} times')
print(f'2 appeared {f2} times')
print(f'3 appeared {f3} times')
print(f'4 appeared {f4} times')
print(f'5 appeared {f5} times')
print(f'6 appeared {f6} times')
```

The code above is quite "ugly," I'm sure. Worse still, if we needed to roll two dice or more, then we'd have to define more variables and write more branching structures. Just thinking about it makes you uncomfortable. At this point, you probably have a question: Is there a way to use one variable to store multiple data values? Is there a way to uniformly operate on multiple data values with the same code? The answer is definitely yes! In Python, we can use container-type variables to store and operate on multiple data values. Let's first introduce lists (`list`), a new data type.

### Creating Lists

In Python, **a list is a data sequence consisting of a series of elements in a specific order**. This means that if we define a list-type variable, **we can use it to store multiple data values**. In Python, we can use the `[]` literal syntax to define lists, with multiple elements separated by commas, as shown below.

```python
items1 = [35, 12, 99, 68, 55, 35, 87]
items2 = ['Python', 'Java', 'Go', 'Kotlin']
items3 = [100, 12.3, 'Python', True]
print(items1)  # [35, 12, 99, 68, 55, 35, 87]
print(items2)  # ['Python', 'Java', 'Go', 'Kotlin']
print(items3)  # [100, 12.3, 'Python', True]
```

> **Note**: Lists can have repeated elements, such as the `35` in `items1`. Lists can have elements of different types, such as `items3`, which contains `int`, `float`, `str`, and `bool` types. However, we typically don't recommend putting elements of different types in the same list, as it becomes inconvenient to operate on them.

You can use the `type()` function to check the type of a variable. If you're interested, you can check what type `items1` is. Because lists can store multiple elements and are a container-type data type, when naming list variables, we usually use plural nouns.

Additionally, you can use Python's built-in `list()` function to convert other sequences into lists. To be precise, `list()` is not an ordinary function but a constructor for creating list objects. We'll discuss objects and constructors in later lessons.

```python
items4 = list(range(1, 10))
items5 = list('hello')
print(items4)  # [1, 2, 3, 4, 5, 6, 7, 8, 9]
print(items5)  # ['h', 'e', 'l', 'l', 'o']
```

> **Note**: `range(1, 10)` produces an integer sequence from `1` to `9`. When passed to the `list()` constructor, it creates a list of integers from `1` to `9`. A string is a sequence of characters. The code `list('hello')` creates a list using the characters from the string `'hello'`.

### List Operations

We can use the `+` operator to concatenate two lists. The concatenation operation joins the elements from both lists into a single list, as shown below.

```python
items5 = [35, 12, 99, 45, 66]
items6 = [45, 58, 29]
items7 = ['Python', 'Java', 'JavaScript']
print(items5 + items6)  # [35, 12, 99, 45, 66, 45, 58, 29]
print(items6 + items7)  # [45, 58, 29, 'Python', 'Java', 'JavaScript']
items5 += items6
print(items5)  # [35, 12, 99, 45, 66, 45, 58, 29]
```

We can use the `*` operator to repeat lists. The `*` operator repeats list elements a specified number of times. Let's add two lines to the code above, as shown below.

```python
print(items6 * 3)  # [45, 58, 29, 45, 58, 29, 45, 58, 29]
print(items7 * 2)  # ['Python', 'Java', 'JavaScript', 'Python', 'Java', 'JavaScript']
```

We can use the `in` or `not in` operator to check if an element is in a list. Let's add two more lines to the code above, as shown below.

```python
print(29 in items6)  # True
print(99 in items6)  # False
print('C++' not in items7)     # True
print('Python' not in items7)  # False
```

Since lists have multiple elements arranged in a specific order, when we want to operate on a specific element in a list, we can use the `[]` operator. By specifying the position of the element in `[]`, we can access that element. This operation is called indexing. It's important to note that the position in `[]` can be an integer from `0` to `N - 1` or from `-1` to `-N`, called positive indexing and negative indexing respectively, where `N` is the number of elements in the list. For positive indexing, `[0]` accesses the first element and `[N - 1]` accesses the last element. For negative indexing, `[-1]` accesses the last element and `[-N]` accesses the first element, as shown below.

```python
items8 = ['apple', 'waxberry', 'pitaya', 'peach', 'watermelon']
print(items8[0])   # apple
print(items8[2])   # pitaya
print(items8[4])   # watermelon
items8[2] = 'durian'
print(items8)      # ['apple', 'waxberry', 'durian', 'peach', 'watermelon']
print(items8[-5])  # apple
print(items8[-4])  # waxberry
print(items8[-1])  # watermelon
items8[-4] = 'strawberry'
print(items8)      # ['apple', 'strawberry', 'durian', 'peach', 'watermelon']
```

When using indexing, avoid index out-of-bounds errors. For `items8` above, if we access `items8[5]` or `items8[-6]`, we'll get an `IndexError` with the message "list index out of range." For `items8` with five elements, valid positive indices are `0` to `4`, and valid negative indices are `-1` to `-5`.

If we want to access multiple elements in a list at once, we can use slicing. Slicing is an operation of the form `[start:end:stride]`, where `start` is the starting position, `end` is the ending position (the element at the end position is not accessed), and `stride` is the step size, or the increment. For example, if the first element we access is at `start`, then the second element is at `start + stride`, and of course `start + stride` must be less than `end`. Let's add the following statements to access list elements using slicing.

```python
print(items8[1:3:1])     # ['strawberry', 'durian']
print(items8[0:3:1])     # ['apple', 'strawberry', 'durian']
print(items8[0:5:2])     # ['apple', 'durian', 'watermelon']
print(items8[-4:-2:1])   # ['strawberry', 'durian']
print(items8[-2:-6:-1])  # ['peach', 'durian', 'strawberry', 'apple']
```

> **Reminder**: Look at the last line in the code above. Think about how slicing works when the stride is negative.

If the `start` value equals `0`, it can be omitted in the slicing operation. If the `end` value equals `N` (the number of list elements), it can be omitted. If the `stride` value equals `1`, it can also be omitted. Therefore, the following code has the exact same effect as the code above.

```python
print(items8[1:3])     # ['strawberry', 'durian']
print(items8[:3:1])    # ['apple', 'strawberry', 'durian']
print(items8[::2])     # ['apple', 'durian', 'watermelon']
print(items8[-4:-2])   # ['strawberry', 'durian']
print(items8[-2::-1])  # ['peach', 'durian', 'strawberry', 'apple']
```

In fact, we can also modify list elements through slicing. For example, let's add one more line to the code above.

```python
items8[1:3] = ['x', 'o']
print(items8)  # ['apple', 'x', 'o', 'peach', 'watermelon']
```

Two lists can also be compared with relational operators. We can compare whether two lists are equal or compare their sizes, as shown below.

```python
nums1 = [1, 2, 3, 4]
nums2 = list(range(1, 5))
nums3 = [3, 2, 1]
print(nums1 == nums2)  # True
print(nums1 != nums2)  # False
print(nums1 <= nums3)  # True
print(nums2 >= nums3)  # False
```

> **Note**: `nums1` and `nums2` above have identical corresponding elements, so the result of `==` is `True`. When comparing `nums2` and `nums3`, since the first element of `nums2` is `1`, which is less than the first element of `nums3`, which is `3`, the result of `nums2 >= nums3` is `False`. List relational comparisons aren't commonly used in practice. If you really don't understand, you can skip it and not worry about it.

### Traversing Elements

To access each element in a list one by one, you can use a `for-in` loop in two ways.

**Method 1**: Traverse list elements using indexing in the loop structure.

```python
languages = ['Python', 'Java', 'C++', 'Kotlin']
for index in range(len(languages)):
    print(languages[index])
```

Output:

```
Python
Java
C++
Kotlin
```

> **Note**: The `len()` function above gets the number of elements `N` in the list, and `range(N)` creates a range from `0` to `N-1`, which is perfect for using as list indices.

**Method 2**: Loop directly over the list; the loop variable represents each list element.

```python
languages = ['Python', 'Java', 'C++', 'Kotlin']
for language in languages:
    print(language)
```

Output:

```
Python
Java
C++
Kotlin
```

### Summary

Now we can refactor the "roll a die 6000 times and count occurrences" code using our knowledge of lists.

```python
"""
Roll a single die 6000 times and count occurrences of each face

Author: Luo Hao
Version: 1.1
"""
import random

counters = [0] * 6
# Simulate rolling the die and count occurrences of each face
for _ in range(6000):
    face = random.randrange(1, 7)
    counters[face - 1] += 1
# Output the occurrences of each face
for face in range(1, 7):
    print(f'{face} appeared {counters[face - 1]} times')
```

In the code above, the six elements in the `counters` list represent the occurrences of faces 1 to 6. Initially, all six elements are 0. Next, we simulate rolling the die using random numbers from 1 to 6. If we roll a 1, we increment `counters[0]` by 1; if we roll a 2, we increment `counters[1]` by 1, and so on. Experience the difference: with the list data type combined with loop structures, our data processing is now batch-based. This makes the refactored code much simpler and more elegant than the previous version.
