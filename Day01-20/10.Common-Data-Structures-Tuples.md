## Common Data Structures: Tuples

In the previous lessons, we discussed lists, a container-type data type. Now we'll introduce another container type called tuples (`tuple`).

### Tuple Definition and Operations

A tuple is a sequence of multiple elements arranged in a specific order, similar to lists. The key difference is that **tuples are immutable types**. Once defined, a tuple's elements cannot be added, deleted, or modified. Tuples support the same operators as lists.

```python
# Define a 3-tuple
t1 = (35, 12, 98)
# Define a 4-tuple
t2 = ('Luo Hao', 45, True, 'Sichuan')

# Check type
print(type(t1))  # <class 'tuple'>

# Get length
print(len(t1))   # 3

# Indexing
print(t1[0])     # 35
print(t1[-1])    # 98

# Slicing
print(t2[:2])    # ('Luo Hao', 45)

# Concatenation
t3 = t1 + t2
print(t3)

# Membership test
print(12 in t1)  # True
```

**Important Note**: A tuple with one element requires a comma: `('hello',)` or `(100,)`. Without the comma, `('hello')` is just a string.

### Packing and Unpacking

When we assign comma-separated values to a variable, they're packed into a tuple. When we assign a tuple to multiple variables, it's unpacked.

```python
# Packing
a = 1, 10, 100
print(type(a))   # <class 'tuple'>

# Unpacking
i, j, k = a
print(i, j, k)   # 1 10 100

# Unpacking with *
x, y, *z = a
print(x, y, z)   # 1 10 [100]
```

### Swapping Variables

In Python, swapping variable values is simple:

```python
a, b = b, a
```

### Tuples vs. Lists

**Why have tuples if we have lists?**

1. **Immutability is thread-safe**: Immutable types have lower synchronization overhead in multithreaded environments.
2. **Performance**: Tuples are faster to create than lists.
3. **Use as Dictionary Keys**: Only immutable types can be dictionary keys, and tuples can be, while lists cannot.

### Summary

**Both lists and tuples are container types** that hold multiple elements in order. **Lists are mutable; tuples are immutable**. Both support concatenation, membership testing, indexing, and slicing operations. **We recommend using list comprehensions for creating lists** as they're efficient and elegant.
