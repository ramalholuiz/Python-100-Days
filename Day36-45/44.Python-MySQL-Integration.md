# Python MySQL Database Integration

In Python 3, we can use `mysqlclient` or `pymysql` libraries to connect to MySQL and implement data persistence. Their usage is identical except for module names. We recommend `pymysql` (pure Python) for easier installation. Using the previously created `hrs` database, we'll demonstrate database operations through Python programs.

## Connecting to MySQL

First, install `pymysql`. For MySQL 8 support, also install `cryptography` for password authentication:

```bash
pip install pymysql cryptography
```

Five steps for `pymysql` MySQL operations:

1. **Create connection**: MySQL provides TCP-based network services. Connect using `pymysql`'s `connect` function, specifying host, port, username, password, database, and charset—returns a Connection object.
2. **Get cursor**: After successful connection, send SQL statements to the server. Get a Cursor object using the connection's `cursor` method.
3. **Execute SQL**: Use the cursor's `execute` method to send SQL statements.
4. **Commit/Rollback**: For insert/delete/update, commit or rollback transactions (transactions are enabled by default). For select, fetch results using `fetchone`, `fetchmany`, or `fetchall`.
5. **Close connection**: Close the connection to release resources, typically in a `finally` block.

## Code Examples

### Insert Data

```python
import pymysql

no = int(input('Department ID: '))
name = input('Department Name: ')
location = input('Location: ')

# 1. Create connection
conn = pymysql.connect(host='127.0.0.1', port=3306,
                       user='guest', password='Guest.618',
                       database='hrs', charset='utf8mb4')
try:
    # 2. Get cursor
    with conn.cursor() as cursor:
        # 3. Execute SQL
        affected_rows = cursor.execute(
            'insert into `tb_dept` values (%s, %s, %s)',
            (no, name, location)
        )
        if affected_rows == 1:
            print('Department added successfully!')
    # 4. Commit transaction
    conn.commit()
except pymysql.MySQLError as err:
    conn.rollback()
    print(type(err), err)
finally:
    # 5. Close connection
    conn.close()
```

> **Note**: `127.0.0.1` is the loopback address (localhost). `guest` is a pre-created user with insert, delete, update, select permissions on `hrs`. Don't use the `root` admin account—it's too dangerous. Create a user with:
>
> ```sql
> create user 'guest'@'%' identified by 'Guest.618';
> grant insert, delete, update, select on `hrs`.* to 'guest'@'%';
> ```

For bulk inserts, use `executemany` for better performance.

### Delete Data

```python
import pymysql

no = int(input('Department ID: '))

# 1. Create connection
conn = pymysql.connect(host='127.0.0.1', port=3306,
                       user='guest', password='Guest.618',
                       database='hrs', charset='utf8mb4',
                       autocommit=True)
try:
    # 2. Get cursor
    with conn.cursor() as cursor:
        # 3. Execute SQL
        affected_rows = cursor.execute(
            'delete from `tb_dept` where `dno`=%s',
            (no, )
        )
        if affected_rows == 1:
            print('Department deleted successfully!')
finally:
    # 5. Close connection
    conn.close()
```

> **Note**: Add `autocommit=True` to automatically commit after SQL execution, avoiding manual transactions.

### Update Data

```python
import pymysql

no = int(input('Department ID: '))
name = input('Department Name: ')
location = input('Location: ')

conn = pymysql.connect(host='127.0.0.1', port=3306,
                       user='guest', password='Guest.618',
                       database='hrs', charset='utf8mb4')
try:
    with conn.cursor() as cursor:
        affected_rows = cursor.execute(
            'update `tb_dept` set `dname`=%s, `dloc`=%s where `dno`=%s',
            (name, location, no)
        )
        if affected_rows == 1:
            print('Department updated successfully!')
    conn.commit()
except pymysql.MySQLError as err:
    conn.rollback()
    print(type(err), err)
finally:
    conn.close()
```

### Query Data

Query departments:

```python
import pymysql

conn = pymysql.connect(host='127.0.0.1', port=3306,
                       user='guest', password='Guest.618',
                       database='hrs', charset='utf8mb4')
try:
    with conn.cursor() as cursor:
        cursor.execute('select `dno`, `dname`, `dloc` from `tb_dept`')
        row = cursor.fetchone()
        while row:
            print(row)
            row = cursor.fetchone()
except pymysql.MySQLError as err:
    print(type(err), err)
finally:
    conn.close()
```

> **Note**: This approach works well for large result sets. `fetchall` loads everything into memory, which can be inefficient.

Paginate employee data:

```python
import pymysql

page = int(input('Page: '))
size = int(input('Size: '))

conn = pymysql.connect(host='127.0.0.1', port=3306,
                       user='guest', password='Guest.618',
                       database='hrs', charset='utf8mb4')
try:
    with conn.cursor(pymysql.cursors.DictCursor) as cursor:
        cursor.execute(
            'select `eno`, `ename`, `job`, `sal` from `tb_emp` order by `sal` desc limit %s,%s',
            ((page - 1) * size, size)
        )
        for emp_dict in cursor.fetchall():
            print(emp_dict)
finally:
    conn.close()
```

## Practical Example: Export to Excel

Install `openpyxl`:

```bash
pip install openpyxl
```

Export all employees to Excel:

```python
import openpyxl
import pymysql

# Create workbook
workbook = openpyxl.Workbook()
sheet = workbook.active
sheet.title = 'Employee Information'
sheet.append(('ID', 'Name', 'Position', 'Salary', 'Bonus', 'Department'))

conn = pymysql.connect(host='127.0.0.1', port=3306,
                       user='guest', password='Guest.618',
                       database='hrs', charset='utf8mb4')
try:
    with conn.cursor() as cursor:
        cursor.execute(
            'select `eno`, `ename`, `job`, `sal`, coalesce(`comm`, 0), `dname` '
            'from `tb_emp` natural join `tb_dept`'
        )
        row = cursor.fetchone()
        while row:
            sheet.append(row)
            row = cursor.fetchone()
    workbook.save('hrs.xlsx')
except pymysql.MySQLError as err:
    print(err)
finally:
    conn.close()
```
